ADM Supplemental Unit

Python Programming Crash Course

Rebuild the Python skills you need for the VEX CTE Workcell by reading, tracing, debugging, modifying, and writing realistic Workcell-style Python code. No robotic arm is required for this crash course.

Start Lesson P.1Back to ADM
Course Goal

Python through industrial automation

Every lesson uses Workcell movement, routing, palletizing, repetition, and reusable robot actions as the programming context. Students can edit and run code directly in the browser while the site simulates Workcell commands as text output.

How each lesson works

Learn → Check → Predict → Fix → Modify → Program

Learn It: read a short explanation tied to the VEX Workcell.

Check It: answer built-in questions and reveal the answers only after attempting them.

Predict It: trace Workcell code and predict what it would do.

Fix It: debug syntax, indentation, variable, or logic errors.

Modify It: change working code to meet a new requirement.

Program It: write a short Workcell solution independently.

Mastery Gate: confirm you can explain and apply the skill before moving on.

Interactive Code-Only Practice

Run Python in the browser

This crash course is entirely code-based. Each lesson includes an editable Python Practice Lab with Run, Reset, output, and error feedback. VEX-style arm commands are simulated as text, so no Workcell hardware is required.

Edit

Change starter code

Experiment with variables, conditions, loops, functions, and Workcell-style commands directly on the lesson page.

Run

Run Python directly on the lesson page

See printed output, simulated arm actions, and Python error messages without installing software or connecting hardware.

Recover

Reset and try again

Reset the starter code at any time. Long-running code is automatically stopped so an accidental infinite loop does not lock the lesson.
