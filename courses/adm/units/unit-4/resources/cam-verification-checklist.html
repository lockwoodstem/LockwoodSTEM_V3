CAM and Toolpath Verification Checklist

Verify the digital manufacturing package before post-processing and machine setup.

Name/Team: ____________________
Date: ____________

Setup Verification

  • Fusion Manufacture setup and DMC2 Mini machining environment confirmed
  • Correct stock size and orientation
  • Correct work coordinate system and program origin
  • Approved tools and holders
  • Approved speeds, feeds, stepdowns, and stepovers
  • Clearance and retract heights verified
  • Workholding represented and clear

Simulation Verification

  • All operations simulated
  • Rapid moves reviewed
  • Tool and holder collisions checked
  • Clamp and fixture clearance checked
  • Remaining stock reviewed
  • Exterior contour scheduled after internal features
  • Estimated cycle time recorded

Post-Processing Verification

  • Teacher-validated Fusion Mach3Mill post selected
  • Correct units and positioning mode
  • Fusion origin matches the approved Mach3 work zero / G54 plan
  • Tool numbers, manual/automatic tool-change plan, and DMC2 Mini spindle-control method checked
  • Feeds and speeds checked
  • Safe startup, retract, and program end checked
  • Approved Fusion version and .tap production file frozen

Mach3 File Verification

  • .tap file loads in the approved DMC2 Mini Mach3 profile
  • Toolpath display matches Fusion direction and extents
  • Units, work zero, safe Z, minimum Z, and final position verified
  • Raised-Z or single-block dry run approved
  • Feed override, Feed Hold, Stop, Reset, and emergency-stop procedures confirmed
