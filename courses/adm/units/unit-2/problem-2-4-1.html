ADM Problem 2.4.1

Coordinated Workcell System Challenge

Integrate multiple VEX CTE Workcells into one coordinated manufacturing system that senses, communicates, routes products, and is optimized using data.

Back to Unit 2Student WorkflowWhat You Submit
Unit 2 Progression

Sense → Decide → Move → Communicate → Monitor → Optimize → Integrate

Unit 2 applies the programming foundation from Unit 1 to increasingly connected manufacturing systems.

Learning Targets

By the end of this lesson

  • Coordinate multiple workcells as one manufacturing system.
  • Use VEX and non-VEX sensors to verify system state.
  • Optimize speed, reliability, efficiency, and sensor use with experimental data.
  • Develop a predictive-maintenance plan and reflect on system performance.
Equipment & Systems

What you will use

  • Multiple VEX CTE Workcells
  • VEX and non-VEX sensors
  • AI Vision Sensor as assigned
  • VEXcode EXP
  • Spreadsheet software
Student Workflow

What You Will Do

  1. Form the assigned multi-workcell system and document the final physical configuration.
  2. Define product starting locations, destinations, and required movement between workcells.
  3. Plan communication and sensor verification so subsystems remain synchronized.
  4. Program and test the complete material-flow system.
  5. Run a factorial experiment on selected settings and use results to improve performance.
  6. Develop a predictive-maintenance plan using available motor data.
  7. Demonstrate the final system and complete the unit reflection.
Programming Focus

How coding supports the lesson

Reuse and adapt your best code from sensing, vision, conveyors, pneumatics, handshaking, and robotic-arm work rather than writing one long program from scratch.

What You Will Submit

What You Submit

  • Multi-workcell system plan and project-management evidence
  • Final programs for each participating workcell
  • Successful coordinated-movement demonstration
  • Factorial experiment plan, data, and optimization conclusion
  • Predictive-maintenance plan
  • Unit reflection
