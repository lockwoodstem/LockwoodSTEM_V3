ADM Activity 2.3.2

Design of Experiments & Workcell Optimization

Use a factorial design of experiments to test interacting workcell settings and identify a combination that balances speed, quality, and reliability.

Back to Unit 2Student WorkflowWhat You Submit
Unit 2 Progression

Sense → Decide → Move → Communicate → Monitor → Optimize → Integrate

Unit 2 applies the programming foundation from Unit 1 to increasingly connected manufacturing systems.

Learning Targets

By the end of this lesson

  • Identify factors, levels, and response variables in an engineering experiment.
  • Create a two-level factorial experiment plan.
  • Collect repeatable workcell performance data in a spreadsheet.
  • Select optimized settings using measured trade-offs.
Equipment & Systems

What you will use

  • VEX CTE Workcell
  • VEXcode EXP
  • Spreadsheet software
  • Instructor-approved workcell factors
Student Workflow

What You Will Do

  1. Select two or more workcell settings that may interact, such as conveyor speed and sensor range.
  2. Assign two test levels to each factor and generate every required combination.
  3. Define response variables such as throughput, error rate, or reliability.
  4. Program and run each experimental condition and record results in a spreadsheet.
  5. Analyze the results and justify the best overall setting combination.
Programming Focus

How coding supports the lesson

Modify existing workcell code so experimental factor levels can be changed consistently between trials. The program should make settings easy to identify and repeat.

What You Will Submit

What You Submit

  • Factorial experiment plan
  • Completed spreadsheet with settings and results
  • Graph or summary of measured responses
  • Recommended optimized settings with evidence
