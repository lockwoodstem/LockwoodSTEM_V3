ADM Activity 2.1.4

Sensor-Based Decision Logic

Use calibrated sensor data with conditional logic so the workcell can choose an action and respond safely when a reading is unexpected.

Back to Unit 2Student WorkflowWhat You Submit
Unit 2 Progression

Sense → Decide → Move → Communicate → Monitor → Optimize → Integrate

Unit 2 applies the programming foundation from Unit 1 to increasingly connected manufacturing systems.

Learning Targets

By the end of this lesson

  • Use sensor values inside if / elif / else decision structures.
  • Assign different automated behaviors to different product types.
  • Create a fail-safe response for unexpected sensor data.
  • Debug decision logic using live sensor readings.
Equipment & Systems

What you will use

  • VEX CTE Workcell
  • Optical Sensor
  • Signal Tower
  • Red and green Disks
Student Workflow

What You Will Do

  1. Start with the validated color ranges from Activity 2.1.3.
  2. Create pseudocode or a flowchart that shows the decision path for each expected color.
  3. Program the required behaviors using if / elif / else.
  4. Add an else condition that handles any reading outside the expected ranges with a safe response.
  5. Test with valid products and an unexpected input, then revise the program until its behavior is repeatable.
Programming Focus

How coding supports the lesson

Use the variables, loops, and if / elif / else structures learned in Unit 1. The new skill is applying them to live manufacturing data and designing robust failure behavior.

What You Will Submit

What You Submit

  • Decision flowchart or pseudocode
  • Final commented sensor-decision program
  • Test results for each expected product
  • Evidence of the programmed response to an unexpected reading
