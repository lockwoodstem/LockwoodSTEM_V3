Objective

Use an input threshold to make a decision, then map the sensor range to a servo angle.

Materials

Start with Simulator. No camera or board is needed.

Plan your time

25–35 minutes. Follow your teacher’s schedule.

Learn: how a sensor becomes a decision

An automated workcell follows an input → decision → output cycle. A sensor supplies a measurement, a controller applies a rule, and an actuator changes the system. In this lesson, Studio simulates the sensor on A0, an LED, and a servo. The LED shows a yes/no decision; the servo demonstrates a variable output.

Read a value, compare it, map it

The simulated sensor ranges from 0 to 1023. value > THRESHOLD is a Boolean expression: it produces True or False. With THRESHOLD = 512, a value of 512 is False because it is equal to the threshold; 513 is True. Changing > to >= would change the boundary behavior.

The servo angle uses round(value * 180 / 1023). Dividing by 1023 converts the reading to a fraction of the full range; multiplying by 180 converts that fraction to degrees. The LED threshold and servo angle are separate calculations: changing THRESHOLD changes the LED decision, not the angle.

Worked predictions with THRESHOLD = 512
A0 readingLED decisionServo angle
0False: off0°
512False: off90°
513True: on90° after rounding
1023True: on180°

Read the program before running it

while True repeats the control cycle until you select Stop. Each await waits for a sensor reading or output command to finish. asyncio.sleep(0.5) yields for half a second between cycles, so a sensor change may not appear immediately. The console reports the values used for that cycle.

Predict before opening Studio

Write your expected LED state at 699, 700, and 701 if THRESHOLD becomes 700. Calculate the servo angle at 256. Explain which output will change when the threshold changes. Keep these predictions to compare with your measurements.

Guided investigation

Run the supplied program first without editing it. Test 0, 512, 513, and 1023 and compare with the worked table. Stop, restart Python, change only THRESHOLD to 700, arm the simulator again, and test your three new boundary values. Use the slider for exact values not provided by preset buttons.

For each trial record: threshold, sensor reading, predicted LED/angle, observed LED/angle, and explanation. Test Stop: the LED should turn off and the servo should detach. A detached real servo is not a mechanical brake.

If the result is unexpected

  • No movement: check that Hardware mode is Simulator, hardware is armed, and the program is running.
  • LED stays off at the threshold: equality does not satisfy >.
  • Servo does not change after a threshold edit: the mapping uses the sensor reading, not THRESHOLD.
  • Code changes do not appear: Stop, restart Python, arm again, then Run.

Explain before moving on

Describe the difference between a Boolean output and a proportional output. Why do readings 512 and 513 produce different LED states but the same rounded servo angle?

Upload and connect

  1. Download the LockwoodStudio.ino file and open it in Arduino IDE. If prompted, allow the IDE to place it in a folder named LockwoodStudio.
  2. Select the correct Arduino Uno R3 or classic Nano board and USB port, then click Upload. The standard Servo library is included with Arduino IDE.
  3. Close Serial Monitor and any application that is using the serial port.
  4. Open Studio, choose USB Arduino, select Connect board, and wait for Firmware v1 ready.
  5. Verify wiring and safe servo travel with your teacher, then select Arm hardware and run the lesson code. Select Stop when finished.

Uno R3 / classic Nano: built-in LED on D13, servo signal on D9, potentiometer center pin on A0 with outer pins connected to 5V and GND. Use a suitable regulated external servo supply with common ground; disconnect power before wiring.

Safety: Test with an unloaded servo first. The firmware turns off the LED and detaches servo control after a communication timeout, but detaching does not remove servo power or mechanically stop a moving load.

Build & test

  1. Open this lesson as a new project. Keep Hardware mode on Simulator, then select Arm hardware.
  2. Select Run. Move Sensor A0 through 0, 512, 513 and 1023 while the program runs. Watch the LED, servo arm and console.
  3. Record which value first turns the LED on. Explain why 512 and 513 produce different decisions.
  4. Press Stop. Verify the LED is off and the servo is detached. Restart Python, change THRESHOLD to 700, arm again, and repeat.
  5. For a teacher-approved board trial, stop first, choose USB Arduino, connect the flashed board and arm it. Use an A0 potentiometer instead of the simulator slider. Keep the servo unloaded.
Read the Python starter
import asyncio

THRESHOLD = 512
print("Move Sensor A0. Press Stop when you finish testing.")
while True:
    value = await arduino.sensor()
    angle = round(value * 180 / 1023)
    led_on = value > THRESHOLD
    await arduino.led(led_on)
    await arduino.servo(angle)
    print(f"A0={value} | LED={led_on} | servo={angle} degrees")
    await asyncio.sleep(0.5)
