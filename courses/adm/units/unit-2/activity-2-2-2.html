External Sensors: Analog & Digital

Connect non-VEX sensors to the EXP Brain, distinguish analog from digital data, and build a reusable program for collecting sensor information.

Objective

Work toward the lesson goal: External Sensors: Analog & Digital. Use the directions and success criteria in the activity below.

Materials

For the online work: a browser and your engineering notebook. Follow the activity’s materials list for any physical build, and get teacher approval before using equipment.

Plan your time

Suggested work block: 45–60 minutes. Physical builds and projects may span several classes; follow your teacher’s schedule.

Learning Targets

By the end of this lesson

  • Differentiate analog and digital sensor signals.
  • Safely connect non-VEX 3-Wire sensors to the EXP Brain.
  • Read and display sensor values in VEXcode EXP.
  • Organize or export sensor data for later analysis.
Equipment & Systems

What you will use

  • VEX CTE Workcell
  • EXP Brain 3-Wire ports
  • Limit switch
  • Light sensor
  • Sound sensor
  • Tilt sensor
  • Flex sensor
Student Workflow

What You Will Do

  1. Inspect the 3-Wire electrical interface and verify correct connector orientation.
  2. Build a generic Python sensor-reading program.
  3. Test a digital sensor and an analog sensor and compare the data they return.
  4. Adapt the same program to instructor-assigned sensors such as light, sound, tilt, or flex.
  5. Record or export a useful sample of sensor data.
Programming Focus

How coding supports the lesson

Configure non-VEX sensors in Python, read values inside a loop, and print measurements to the Console and Brain. The goal is a reusable sensor-reading pattern that can be adapted to different hardware.

What You Will Submit

What You Submit

  • Analog vs. digital sensor comparison
  • Generic commented sensor-reading program
  • Recorded data from assigned sensors
  • Short explanation of electrical connection and sensor type
