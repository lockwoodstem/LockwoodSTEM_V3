ADM Activity 2.1.3

Optical Sensing & Color Detection

Calibrate the Optical Sensor so product color becomes reliable data that later lessons can use for automated sorting decisions.

Back to Unit 2Student WorkflowWhat You Submit
Unit 2 Progression

Sense → Decide → Move → Communicate → Monitor → Optimize → Integrate

Unit 2 applies the programming foundation from Unit 1 to increasingly connected manufacturing systems.

Learning Targets

By the end of this lesson

  • Explain how the Optical Sensor measures color information.
  • Collect and interpret hue data for different objects.
  • Establish reliable color-identification ranges.
  • Evaluate how lighting and object position can affect sensor reliability.
Equipment & Systems

What you will use

  • VEX CTE Workcell
  • Optical Sensor
  • Red and green Disks
  • VEXcode EXP Console
Student Workflow

What You Will Do

  1. Collect Optical Sensor readings for the available colored parts.
  2. Compare repeated readings and determine useful hue ranges for each product type.
  3. Move or reposition objects slightly and observe whether the readings remain reliable.
  4. Test at least one environmental change, such as lighting or sensor-to-object position.
  5. Document the final identification ranges that will be used in Activity 2.1.4.
Programming Focus

How coding supports the lesson

Use variables to store sensor values and print them to the Console or Brain. Do not build the full sorting logic yet; first prove the sensor data is reliable.

What You Will Submit

What You Submit

  • Optical-sensor calibration data
  • Final hue / identification ranges
  • Short reliability analysis
  • Commented sensor-reading program
