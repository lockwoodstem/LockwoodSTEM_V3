ADM Activity 2.3.1

Predictive Maintenance & Motor Health

Use workcell motor data and manufacturing data sets to recognize patterns that can warn of equipment problems before failure occurs.

Back to Unit 2Student WorkflowWhat You Submit
Unit 2 Progression

Sense → Decide → Move → Communicate → Monitor → Optimize → Integrate

Unit 2 applies the programming foundation from Unit 1 to increasingly connected manufacturing systems.

Learning Targets

By the end of this lesson

  • Differentiate reactive, preventive, and predictive maintenance.
  • Interpret motor temperature, velocity, and current data.
  • Identify combinations of measurements that may indicate developing faults.
  • Use a manufacturing data set to look for failure patterns.
Equipment & Systems

What you will use

  • VEX CTE Workcell
  • VEXcode EXP Console
  • Motor-data program
  • Wafer-transfer-robot data set
  • Spreadsheet software
Student Workflow

What You Will Do

  1. Run the provided motor-data program and establish normal workcell behavior.
  2. Interpret changes in temperature, current, and velocity under different conditions.
  3. Identify combinations of signals that deserve operator attention.
  4. Analyze the wafer-transfer-robot data set for patterns associated with reduced reliability or missed pickups.
  5. Propose a simple predictive-maintenance rule based on evidence.
Programming Focus

How coding supports the lesson

Use the VEXcode Console as a data source. Programming supports data collection; the primary skill is diagnosing patterns rather than writing new control structures.

What You Will Submit

What You Submit

  • Maintenance-strategy comparison
  • Motor-health observations and warning indicators
  • Wafer-transfer-robot data analysis
  • Evidence-based predictive-maintenance recommendation
