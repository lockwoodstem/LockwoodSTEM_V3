Objective

Create a color mask and use measured image area to distinguish a green object from background noise.

Materials

A webcam and a green object or piece of paper. Keep faces out of the camera view.

Plan your time

30–40 minutes. Follow your teacher’s schedule.

Build & test

  1. Open the lesson, start the camera and point it at a clear workspace. Live vision mode is selected for you.
  2. Select Run live. Place a green object in the center of the view. Compare the original image with the mask and bounding boxes.
  3. Remove the object, then test a non-green object. Record whether each trial gives the expected result.
  4. Change lighting or distance. Stop, restart Python, adjust MIN_AREA, and run again. Explain any missed detections or false detections.
  5. Press Stop and verify the camera switches off. Write your observations before exporting the submission.
Read the Python starter
import cv2

MIN_AREA = 400

def process_frame(frame):
    rgb = cv2.cvtColor(frame, cv2.COLOR_RGBA2RGB)
    hsv = cv2.cvtColor(rgb, cv2.COLOR_RGB2HSV)
    mask = cv2.inRange(hsv, (35, 70, 60), (85, 255, 255))
    output = cv2.cvtColor(mask, cv2.COLOR_GRAY2RGBA)
    count = 0
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for contour in contours:
        if cv2.contourArea(contour) >= MIN_AREA:
            x, y, w, h = cv2.boundingRect(contour)
            cv2.rectangle(output, (x, y), (x+w, y+h), (255, 200, 40, 255), 2)
            count += 1
    cv2.putText(output, f"Green objects: {count}", (10, 25),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 200, 40, 255), 2)
    return output

Evidence to collect

  • I tested green, non-green and empty scenes.
  • I tested a second lighting condition or distance.
  • I explained one false detection or limitation and verified camera Stop.

Observations & reflection

Record at least three trials (object, lighting/distance, expected result, observed result). What did changing MIN_AREA do?

Extend the challenge

Tune the HSV bounds for a different color. Explain why a fixed threshold is sensitive to lighting.
