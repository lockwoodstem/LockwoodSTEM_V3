Detect a colored object

Create a color mask and use measured image area to distinguish a green object from background noise.

Objective

Create a color mask and use measured image area to distinguish a green object from background noise.

Materials

A webcam and a green object or piece of paper. Keep faces out of the camera view.

Plan your time

30–40 minutes. Follow your teacher’s schedule.

Learn: how an image becomes a measurement

A camera frame is a grid of pixels. A color detector checks each pixel against a rule; it does not understand what the object is. Here, a green notebook, green paper, and a green background can all match. You will learn to separate color evidence from a claim that a particular object is present.

Follow the image-processing steps

  1. Convert the frame: Studio supplies RGBA pixels. The starter removes the alpha channel, then converts RGB into HSV: hue (color family), saturation (color strength), and value (brightness).
  2. Make a mask: cv2.inRange checks whether all three HSV components lie within the lower and upper bounds. Matching pixels become white (255); others become black (0).
  3. Find regions: contours outline connected shapes in the mask. A contour can come from the intended object or background noise.
  4. Filter and annotate: regions with contour area at least MIN_AREA receive a bounding box and contribute to the displayed count.

The starter uses HSV bounds (35, 70, 60) through (85, 255, 255). In this OpenCV representation hue runs from 0 to 179, while saturation and value run from 0 to 255. These green bounds are a starting point; lighting, shadows, and reflections can change whether pixels match.

Worked example: the area filter

With MIN_AREA = 400, a contour area of 250 is ignored, while 400 or 900 passes. Raising MIN_AREA can reject small specks but may also reject a small or distant target. Area is measured in image pixel units; it is not the physical area of the object. A bounding box is only an annotation, not proof that the detection is correct.

Predict before opening Studio

Predict the result for an empty view, a green object, and a non-green object. Then predict what happens if you move the green object farther from the camera without changing its size. Identify one situation in which the detector could report green even though your intended target is absent.

Guided investigation

Use a clear background and steady lighting. Compare the camera image with the processed mask: white regions show the color test, while boxes show which contours passed the area filter. Run green, non-green, and empty trials. Next, keep the object and lighting constant while changing distance. Stop and restart Python before changing MIN_AREA, then repeat the same scenes.

Record object/background, distance or lighting condition, MIN_AREA, predicted result, observed count, and whether the result was correct. A false positive reports a target when it is absent; a false negative misses a target that is present. Include one limitation even if all your planned trials succeed.

If the result is unexpected

  • Mask is all black: check that the camera is running, the object is green under the current lighting, and Live vision mode is selected.
  • White pixels appear but no box: the region may be smaller than MIN_AREA.
  • Too many boxes: inspect green background objects or fragmented regions; simplify the scene before changing one parameter.
  • Camera access is denied: allow camera permission for the site, then select Start camera again.

Explain before moving on

Explain why changing MIN_AREA changes boxes and counts but does not change which pixels are white in the mask. How would you distinguish a color-detection failure from an area-filter failure?

Read the Python starter
import cv2

MIN_AREA = 400

def process_frame(frame):
    rgb = cv2.cvtColor(frame, cv2.COLOR_RGBA2RGB)
    hsv = cv2.cvtColor(rgb, cv2.COLOR_RGB2HSV)
    mask = cv2.inRange(hsv, (35, 70, 60), (85, 255, 255))
    output = cv2.cvtColor(mask, cv2.COLOR_GRAY2RGBA)
    count = 0
    contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    for contour in contours:
        if cv2.contourArea(contour) >= MIN_AREA:
            x, y, w, h = cv2.boundingRect(contour)
            cv2.rectangle(output, (x, y), (x+w, y+h), (255, 200, 40, 255), 2)
            count += 1
    cv2.putText(output, f"Green objects: {count}", (10, 25),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 200, 40, 255), 2)
    return output
