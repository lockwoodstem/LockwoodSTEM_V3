Learn It

Python Idea + Workcell Connection

Real automation often combines repetition and decision-making. A loop can process multiple parts while an if statement chooses a different route for each part.

When one structure is placed inside another, indentation shows which commands belong together.

Trace one loop cycle at a time. Record the variable values before deciding which branch executes.

Worked Example

Trace This Code

Read every line and predict what the program would do before opening the practice check.

for part_number in range(4):
    destination = part_number % 2

    if destination == 0:
        arm.move_to(250, 80, 120)
    else:
        arm.move_to(250, 160, 120)
Practice Check A

Check Your Understanding

  1. What values does part_number % 2 alternate between?

    Check Answer

    0 and 1

  2. Which pallet receives part numbers 0 and 2?

    Check Answer

    The first pallet at (250, 80, 120).

  3. How many total movements occur?

    Check Answer

    4 movements, one per loop cycle.

Rule: If you missed more than one question, reread Learn It and trace the example again before continuing.

1 · Predict It

Trace the Code

Which pallet is selected for each of the four parts?

Do first: Write your answer in your engineering notebook.

Reveal Self-Check

Parts 0 and 2 go to the first pallet; parts 1 and 3 go to the second pallet.

2 · Fix It

Debug the Program

Find and correct every error before opening the answer.

for part_number in range(4):
    if part_number < 2:
    arm.move_to(250, 80, 120)
    else
        arm.move_to(250, 160, 120)
Reveal Debugging Check

Indent the first movement under the if, and add a colon after else.

3 · Modify It

Change Working Code

Change the logic so the first three parts go to Pallet 1 and the fourth goes to Pallet 2.

Success Check

  • Your code is syntactically correct.
  • The change affects only the intended Workcell behavior.
  • You can explain what changed and why.

Evidence: Paste the revised code into your engineering notebook.

Build It Yourself
