Using loops to repeat predictable manufacturing actions.

Learn It

Python Idea + Workcell Connection

A for loop repeats a block of code a known number of times. range(3) produces the values 0, 1, and 2, so the loop runs three times.

The loop body must be indented. Every indented command is repeated once per loop cycle.

For loops are useful when the Workcell must repeat a known number of identical production cycles.

Worked Example

Trace This Code

Read every line before opening the practice check.

for part_number in range(3):
    print("Processing part", part_number + 1)
    arm.move_to(100, 150, 120)
    arm.move_to(100, 150, 45)
    arm.set_end_effector_magnet(True)
    arm.move_to(100, 150, 120)
Practice Check A

Check Your Understanding

  1. How many times does range(3) repeat?

    Check Answer

    3 times

  2. What are the raw values of part_number?

    Check Answer

    0, 1, 2

  3. Why does the print statement use part_number + 1?

    Check Answer

    It displays human-friendly part numbers 1, 2, and 3.
