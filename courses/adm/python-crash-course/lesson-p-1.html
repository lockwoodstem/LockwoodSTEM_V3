ADM Python P.1

Reading Workcell Python

Program order, comments, method calls, and predicting robot behavior.

Start PracticeCrash Course Home
Workcell Connection

Program the robot, not a worksheet

Use Python to describe and control realistic VEX Workcell behavior. Trace before you test.

Learning Targets

  • Read Python from top to bottom
  • Identify comments and method calls
  • Predict the order of Workcell actions

Before You Code

  • Identify the robot action each line represents.
  • Check indentation, colons, parentheses, spelling, and variable names.
  • Verify coordinates and safe motion paths before hardware testing.
  • Do not run the Workcell until instructed.
Guided Example

Read the Workcell Code

# Move above the pickup point
arm.move_to(100, 150, 120)

# Move down to the part
arm.move_to(100, 150, 45)

# Pick up the part
arm.set_end_effector_magnet(True)

# Lift the part
arm.move_to(100, 150, 120)
1 · Predict It

Trace Before Running

Number the four robot actions in the order they occur. What would change if the final movement command were deleted?

Notebook: Write your prediction and explain the line or condition that controls the result.

2 · Fix It

Debug the Program

Find and correct every error. Do not rewrite the entire program unless necessary.

arm.move_to(100, 150, 120)
arm.set_end_effector_magnet(True
arm.move_to(100, 150, 45)

Notebook: List each error and explain why it matters.

3 · Modify It

Change a Working Program

Change the program so the arm moves above the part, lowers to the part, turns the magnet on, and then lifts the part.

Evidence: Paste your revised code into your engineering notebook.

4 · Program It

Build It Yourself

Write a short Workcell sequence that moves to a safe point, approaches a pickup point, activates the magnet, and returns to the safe point.

Requirement: Add useful comments and use descriptive variable/function names.
