Learn It

Python Idea + Workcell Connection

A variable is a named storage location. Instead of repeating a coordinate such as 100 throughout a program, you can store it as pickup_x = 100.

Variables make Workcell programs easier to change. If a pickup location moves, you update the variable once instead of editing every motion command.

Python variable names are case-sensitive: pickup_x and pickupX are different names.

Worked Example

Trace This Code

Read every line and predict what the program would do before opening the practice check.

pickup_x = 100
pickup_y = 150
pickup_z = 45

arm.move_to(pickup_x, pickup_y, 120)
arm.move_to(pickup_x, pickup_y, pickup_z)
arm.set_end_effector_magnet(True)
Practice Check A

Check Your Understanding

  1. What value is stored in pickup_y?

    Check Answer

    150

  2. If pickup_x changes to 140, how many move commands use the new value?

    Check Answer

    Both movement commands use the new x value.

  3. Are pickup_x and pickupX the same variable?

    Check Answer

    No. Python variable names are case-sensitive.
