ADM Python P.10

Workcell Python Skills Challenge

Integrating variables, decisions, loops, and functions in one automation program.

Start PracticeCrash Course Home
Workcell Connection

Program the robot, not a worksheet

Use Python to describe and control realistic VEX Workcell behavior. Trace before you test.

Learning Targets

  • Plan before coding
  • Combine core Python structures
  • Debug and explain a Workcell program

Before You Code

  • Identify the robot action each line represents.
  • Check indentation, colons, parentheses, spelling, and variable names.
  • Verify coordinates and safe motion paths before hardware testing.
  • Do not run the Workcell until instructed.
Guided Example

Read the Workcell Code

pickup_zone = 2
destination = 1
parts_completed = 0

while parts_completed < 3:
    if pickup_zone == 1:
        pickup_x = 100
    elif pickup_zone == 2:
        pickup_x = 160
    else:
        pickup_x = 220

    # Add pickup and pallet movement here

    parts_completed += 1
1 · Predict It

Trace Before Running

Trace the variable values for one complete cycle before adding any robot movement.

Notebook: Write your prediction and explain the line or condition that controls the result.

2 · Fix It

Debug the Program

Find and correct every error. Do not rewrite the entire program unless necessary.

# Challenge debugging:
# 1. Check variable names.
# 2. Check colons.
# 3. Check indentation.
# 4. Check that counters update.
# 5. Check that every destination has a valid route.

Notebook: List each error and explain why it matters.

3 · Modify It

Change a Working Program

Complete the missing pickup and pallet movement using variables instead of repeating coordinates.

Evidence: Paste your revised code into your engineering notebook.

4 · Program It

Build It Yourself

Final challenge: program a three-cycle pick-and-pallet routine. The pickup zone and destination must be controlled by variables, routing must use if/elif/else, repeated work must use a loop, and at least one repeated robot action must be placed in a function.

Requirement: Add useful comments and use descriptive variable/function names.

Exit Ticket

Before You Leave

  1. What Python idea did you use today?
  2. What Workcell behavior did that Python idea control?
  3. What is one error you now know how to recognize?
