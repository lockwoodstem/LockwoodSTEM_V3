Part Inspection & Routing Logic

Write decision logic that determines whether a part passes inspection and where it should be routed.

Start AssignmentBack to Crash Course
10 Points

Use after Lessons P.4–P.5

Practice comparisons, Boolean logic, and if/elif/else routing.

Practice Assignment

What You Need to Do

  1. Create variables for part_height, minimum_height, maximum_height, and destination.
  2. Create a Boolean expression that determines whether the part height is acceptable.
  3. If the part is acceptable, route destination 1 to Pallet 1 and destination 2 to Pallet 2.
  4. If the destination is invalid, print an error message.
  5. If the part fails inspection, route it to a reject location instead of a pallet.

Success Criteria

Check Your Work

  • A part below 45 or above 50 is rejected.
  • A valid part with destination 1 reaches Pallet 1.
  • A valid part with destination 2 reaches Pallet 2.
  • An invalid destination produces a clear error message.
