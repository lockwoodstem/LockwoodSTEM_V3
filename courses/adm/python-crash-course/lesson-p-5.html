Learn It

Python Idea + Workcell Connection

An if statement runs code only when its condition is True. elif adds another condition, and else catches everything that did not match earlier conditions.

Indentation is part of Python syntax. Commands belonging to a condition must be indented underneath it.

This structure is ideal for routing parts to different pallet locations.

Worked Example

Trace This Code

Read every line and predict what the program would do before opening the practice check.

destination = 2

if destination == 1:
    arm.move_to(250, 80, 120)
elif destination == 2:
    arm.move_to(250, 160, 120)
else:
    print("Invalid destination")
Practice Check A

Check Your Understanding

  1. Which branch runs when destination is 2?

    Check Answer

    The elif destination == 2 branch.

  2. Can both the if and elif branches run in this example?

    Check Answer

    No. Once a matching branch is found, the remaining branches are skipped.

  3. What is the purpose of else?

    Check Answer

    It handles any destination that did not match the valid choices.
