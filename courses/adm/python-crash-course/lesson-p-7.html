Learn It

Python Idea + Workcell Connection

A while loop keeps repeating as long as its condition remains True. It is useful when the program should continue until a production target is reached.

The condition must eventually become False. If the variables in the condition never change, the loop can run forever.

A counter such as parts_completed += 1 is a common way to move the loop toward its stopping condition.

Worked Example

Trace This Code

Read every line and predict what the program would do before opening the practice check.

parts_completed = 0
production_goal = 5

while parts_completed < production_goal:
    print("Running cycle")
    parts_completed += 1

print("Production complete")
Practice Check A

Check Your Understanding

  1. What value starts in parts_completed?

    Check Answer

    0

  2. What line moves the loop toward stopping?

    Check Answer

    parts_completed += 1

  3. What danger exists if that line is removed?

    Check Answer

    The condition remains True and the loop can become infinite.
