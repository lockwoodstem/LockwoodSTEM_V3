Learn It

Python Idea + Workcell Connection

A function gives a name to a reusable block of code. This makes longer Workcell programs easier to read, test, and modify.

Values listed in the function definition are parameters. Values supplied when the function is called are arguments.

Functions are especially useful for repeated actions such as pick up, place, move safe, or release.

Worked Example

Trace This Code

Read every line before opening the practice check.

def move_to_pickup(x, y, z):
    arm.move_to(x, y, 120)
    arm.move_to(x, y, z)
    arm.set_end_effector_magnet(True)
    arm.move_to(x, y, 120)

move_to_pickup(100, 150, 45)
Practice Check A

Check Your Understanding

  1. What are the three parameters?

    Check Answer

    x, y, and z

  2. What x-value is used when the function is called?

    Check Answer

    100

  3. How many arm movement commands are inside the function?

    Check Answer

    3 movement commands

Rule: If you missed more than one question, reread Learn It and trace the example again before continuing.
