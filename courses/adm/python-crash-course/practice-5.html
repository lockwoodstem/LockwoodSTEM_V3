Workcell Programming Mini-Challenge

Create a complete simulated production program using the major Python skills from the crash course.

Start AssignmentBack to Crash Course
30 Points

Use after Lessons P.1–P.10

Integrate variables, calculations, decisions, loops, functions, counters, and error handling.

Practice Assignment

What You Need to Do

  1. Define three pickup zones using variables.
  2. Define two pallet destinations.
  3. Create reusable pickup and placement functions.
  4. Use a loop to process at least six parts.
  5. Use decision logic to select the correct pickup zone and pallet destination.
  6. Track the number of successfully processed parts.
  7. Detect at least one invalid input and print a clear error instead of attempting the move.
  8. Print a final production summary.

Success Criteria

Check Your Work

  • The program uses variables rather than repeating raw coordinates unnecessarily.
  • Functions handle repeated movement sequences.
  • A loop performs the production cycles.
  • Decision logic selects locations and catches invalid choices.
  • The program produces a clear final summary.
  • You can explain how changing one pickup-zone variable affects the program.
Submission

What to Turn In

  • Your final Python code copied into the assignment submission.
  • A screenshot of the final output showing that the program ran successfully.
  • One debugging note: identify one problem you encountered and explain how you fixed it.
