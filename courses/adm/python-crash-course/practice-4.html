Reusable Pick-and-Place Functions

Turn repetitive simulated movement sequences into reusable functions.

Start AssignmentBack to Crash Course
10 Points

Use after Lesson P.9

Practice creating functions with parameters and removing repeated Workcell code.

Practice Assignment

What You Need to Do

  1. Create a function named pick_part(x, y, z).
  2. Create a function named place_part(x, y, z).
  3. Each function must use a safe travel height before moving down.
  4. The pick function must turn the magnet ON; the place function must turn it OFF.
  5. Call the functions to move two simulated parts between different coordinates.
  6. Do not duplicate the full movement sequence outside the functions.

Success Criteria

Check Your Work

  • Both functions accept X, Y, and Z parameters.
  • The magnet turns on only during pickup and off during placement.
  • Both functions return to the defined safe height.
  • The main program is shorter and clearer because repeated movement logic is inside functions.
Submission

What to Turn In

  • Your final Python code copied into the assignment submission.
  • A screenshot of the final output showing that the program ran successfully.
  • One debugging note: identify one problem you encountered and explain how you fixed it.
