Practice Assignment

What You Need to Do

  1. Create variables for pickup X, Y, Z and a safe Z height.
  2. Calculate the safe Z position from the pickup Z plus an offset rather than typing the safe height directly.
  3. Print the pickup position and calculated safe height.
  4. Use the variables in at least three arm.move_to() commands.
  5. Modify one variable and verify that the simulated movement output changes without rewriting the movement commands.

Success Criteria

Check Your Work

  • The program contains no hard-coded duplicate pickup coordinates inside the movement commands.
  • The safe height is calculated using variables.
  • The output clearly shows the coordinate values before movement.
  • Changing pickup_x changes every movement that depends on it.
Submission

What to Turn In

  • Your final Python code copied into the assignment submission.
  • A screenshot of the final output showing that the program ran successfully.
  • One debugging note: identify one problem you encountered and explain how you fixed it.
