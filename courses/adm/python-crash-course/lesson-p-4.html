Learn It

Python Idea + Workcell Connection

A comparison asks a yes/no question and produces either True or False. Automation programs use these results to decide what should happen next.

Use == to compare values. A single = assigns a value to a variable.

Comparisons can represent inspection limits, destinations, production counts, or other Workcell conditions.

Worked Example

Trace This Code

Read every line and predict what the program would do before opening the practice check.

part_height = 48
max_height = 50

part_ok = part_height <= max_height

print(part_ok)
Practice Check A

Check Your Understanding

  1. Does 48 <= 50 evaluate to True or False?

    Check Answer

    True

  2. What is the difference between = and ==?

    Check Answer

    = assigns a value; == compares two values.

  3. Which operator means 'not equal to'?

    Check Answer

    !=

Rule: If you missed more than one question, reread Learn It and trace the example again before continuing.
