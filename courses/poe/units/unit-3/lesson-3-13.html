Configure arm and claw motors

Identify the actual V5 smart ports, motor directions and power-off inspection requirements.

Map momentary controller commands

Use paired buttons for arm up/down and claw open/close. Releasing buttons must stop motion.

Keep your original driving program

Extend the tested tank or arcade drive code from 3.8–3.9 using short, nonblocking functions.

Check motion limits

The starter code does not automatically enforce arm travel limits. Do not run a motor into a mechanical stop.

VEXcode V5 Python — Starter Functions

This example assumes the controller, arm motor and claw motor are defined in the VEXcode Devices configuration. Adapt motor names, wiring, and directions. Verify actual API compatibility in your classroom VEXcode installation.

# Extend an existing configured VEXcode V5 Python project.
# Device names must match your VEXcode Devices configuration.
ARM_SPEED = 25
CLAW_SPEED = 20

def arm_step():
    if controller_1.buttonL1.pressing():
        arm_motor.spin(FORWARD, ARM_SPEED, PERCENT)
    elif controller_1.buttonL2.pressing():
        arm_motor.spin(REVERSE, ARM_SPEED, PERCENT)
    else:
        arm_motor.stop()

def claw_step():
    if controller_1.buttonR1.pressing():
        claw_motor.spin(FORWARD, CLAW_SPEED, PERCENT)
    elif controller_1.buttonR2.pressing():
        claw_motor.spin(REVERSE, CLAW_SPEED, PERCENT)
    else:
        claw_motor.stop()

# Place these inside your existing driving loop:
# while True:
#     your_existing_drive_step()
#     arm_step()
#     claw_step()
#     wait(20, MSEC)
#
# This example does not enforce travel limits.
# Test with no payload at low speed and avoid hard stops.
