01 / Programming Concepts

Turn Joystick Signals Into Motion

5 min • Controller safety10 min • Tank vs arcade20 min • Code and field tests5 min • Compare5 min • PDF report

Tank drive

One vertical joystick axis commands the left drive side and another commands the right drive side. Different side speeds produce turns.

Common mapping: Axis 3 (left vertical) → left motor; Axis 2 (right vertical) → right motor.

Arcade drive

A forward/reverse input and a turn input combine to command both sides. The basic mixing rule is left = forward + turn, right = forward − turn, limited to an approved speed range.

Deadband and safe stopping

Small neutral joystick readings can cause unwanted motion. A deadband treats inputs near zero as zero. Release the joysticks and verify the motors stop. Never rely only on the controller for emergency intervention.

Code versus Devices setup

Students must use actual motor port names, motor-reversal settings and controller device names from their VEXcode project. If custom controller code is used, disable any conflicting generated controller-drive code.

Starter Programming Pattern — VEXcode V5 Python

This is a learning example for a VEXcode project that already has left_motor, right_motor and controller_1 configured. Adjust names and physical motor directions. Test at low speed with the drivetrain lifted or supported before driving on the floor.

# Insert within a configured VEXcode V5 Python project.
# Device names are EXAMPLES. Match your Devices setup.
# Disable generated controller drive commands when using custom code:
remote_control_code_enabled = False
DEADBAND = 10
MAX_SPEED = 50

def limit_speed(speed):
    return max(-MAX_SPEED, min(MAX_SPEED, speed))

def drive_side(motor, command):
    speed = limit_speed(command)
    if abs(speed) <= DEADBAND:
        motor.stop()
    elif speed > 0:
        motor.spin(FORWARD, speed, PERCENT)
    else:
        motor.spin(REVERSE, -speed, PERCENT)

def tank_step():
    left = controller_1.axis3.position()
    right = controller_1.axis2.position()
    drive_side(left_motor, left)
    drive_side(right_motor, right)

def arcade_step():
    forward = controller_1.axis3.position()
    turn = controller_1.axis1.position()
    drive_side(left_motor, forward + turn)
    drive_side(right_motor, forward - turn)

# For one program, choose ONE function per loop:
while True:
    tank_step()  # Switch to arcade_step() after testing tank mode
    wait(20, MSEC)

# Confirm motor reversal, physical stop access, and actual port names
# before enabling drivetrain movement.
