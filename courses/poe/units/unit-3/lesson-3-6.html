Device setup

Connect your V5 Brain in VEXcode V5 Python. Confirm both drive-motor smart ports and directions. Use a two-motor drivetrain without gyro configuration appropriate to your physical Clawbot.

Do not assume example motor ports match your rover. Record the actual ports in your report.

Motion commands

Practice moving forward and in reverse, turning left and right, and stopping. Test at a low speed first and make sure the rover travels in the expected direction.

Use an instructor-approved start/stop procedure. Clear the floor and lift or restrain wheels during initial motor-direction verification.

What is a safe stop?

After each test, the rover must cease commanded motion. A physical program-stop procedure is required; do not rely on a long timed program to stop itself if something is wrong.

Open-loop behavior

Programmed movements command a motion without checking sensor feedback. Small differences in gear ratio, wheel diameter and traction can change the resulting motion.

VEXcode Python command reference

These are illustrative commands for a properly configured drivetrain device in a VEXcode V5 Python project—not a complete standalone program. The names and configuration must match your project. For this lesson, use an instructor-approved two-motor Clawbot template.

# Use within a configured VEXcode V5 Python project.
# Test low speeds and limited distances first.
drivetrain.set_drive_velocity(25, PERCENT)
drivetrain.set_turn_velocity(20, PERCENT)
drivetrain.drive_for(FORWARD, 200, MM)
drivetrain.drive_for(REVERSE, 200, MM)
drivetrain.turn_for(LEFT, 90, DEGREES)
drivetrain.turn_for(RIGHT, 90, DEGREES)
drivetrain.stop()

Reference: Official VEX V5 Python Drivetrain API. Verify the exact functions and units supported by your installed VEXcode configuration.

Important sequence: Lesson 3.6 teaches basic commanded movement, not joystick programming. Controller programming is introduced in 3.8. Tug-of-war in 3.7 may use a teacher-approved, safely controlled motor command program; the instructor will specify the start/stop protocol.
