Key Idea

System architecture shows how subsystems, signals, logic, energy, and physical components interact before building begins.

Student Activity

Create a system architecture diagram and mission flowchart before build/program work begins.

Aerospace Connection

Connect the lesson to autonomous rovers, drones, sensors, ground-support systems, actuators, and mission-readiness testing.

Interactive Checkpoints

Question First, Reveal Second

Use the prompts to create discussion before opening the answers.

Which choice sounds most like engineering?

Choose the option that compares system decisions against mission criteria and evidence.

Reveal Answer

Best answer: Compare options against criteria and evidence before deciding. Autonomous systems must be justified with logic, testing, and repeatable performance.

What evidence would you need?

For a system claim, select the proof that shows how the logic or mechanism actually performed.

Reveal Answer

Best evidence: a labeled logic/system diagram plus mission test data, sensor readings, or repeated performance results connected to the claim.

What should the engineer do next?

If a rover or ground-support system works once but fails on the next trial, what is the strongest next step?

Reveal Answer

Engineering move: Record the failure point, identify the likely cause, revise the logic or mechanism, and retest with the same procedure.

Evidence or opinion?

Which statement is strongest: “It looks reliable,” “It completed 4 of 5 trials,” or “We changed the threshold because the sensor triggered early twice”?

Reveal Answer

Strongest: The threshold statement is evidence-based reasoning because it connects a revision to repeated observations. The 4-of-5 result is also useful performance evidence.
