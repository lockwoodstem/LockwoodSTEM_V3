Lesson Targets

What You Will Be Able to Do

Learning Target

I can diagram a system as connected flows of energy, information, materials, and feedback.

Evidence

Aerospace system diagram

Success Looks Like

The diagram correctly identifies the input, controller or process, output, and feedback measurement.

Activity Flow

How the Lesson Moves

1. Trace a familiar aerospace system

Establish the engineering purpose and vocabulary.

2. Classify components by system role

Apply the idea to a specific readiness decision.

3. Create a system diagram with one feedback loop

Produce evidence that can be checked or used later.
