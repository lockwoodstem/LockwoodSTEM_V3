Lesson Targets

What You Will Be Able to Do

Learning Target

I can select a graph type, assign variables to axes, and write a claim supported by the displayed data.

Evidence

Graph and claim-evidence-reasoning response

Success Looks Like

The display matches the data type, axes are labeled with variables and units, and the claim is appropriately qualified.

Activity Flow

How the Lesson Moves

Each step builds the data, motion, or testing reasoning required for today’s deliverable.

1. Match graph to question

Decide whether the task compares categories, change over time, or two numerical variables.

2. Build the display

Place the independent variable on x and the response on y.

3. Write the claim

Reference a visible pattern without extending beyond the tested data.

Lesson Interactive

Plan the Graph and Claim

Apply the lesson concept to a mission-performance scenario. Use the feedback to correct your reasoning before completing the main deliverable.

Investigation

Teams tested launch angles of 20°, 30°, 40°, 50°, and 60° and measured horizontal range in meters.

Choose a display for two numerical variables and write only what the tested data support.
Today’s Work

Main Deliverable

Graph and claim-evidence-reasoning response

Create one focused engineering artifact that demonstrates today’s learning.

  • Create a correctly labeled graph using the assigned dataset.
  • Write a claim-evidence-reasoning paragraph tied directly to the graph.
