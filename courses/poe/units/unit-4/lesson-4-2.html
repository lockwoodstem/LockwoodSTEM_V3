Lesson Targets

What Students Should Be Able To Do

Learning Target

I can identify independent, dependent, and controlled variables and select enough trials for a useful test.

Evidence

Controlled launch-test plan

Success Looks Like

The plan changes one factor, measures one response, controls major conditions, and includes repeated trials.

Activity Flow

How the Lesson Moves

Each step builds the data, motion, or testing reasoning required for today’s deliverable.

1. Define the question

Convert the design question into one variable to change and one response to measure.

2. Control the test

List conditions that must stay constant.

3. Plan repetition

Choose tools, units, and trial count before testing.

Main Deliverable

Controlled launch-test plan

Create one focused engineering artifact that demonstrates today’s learning.

  • Specify measurement units, equipment, and a minimum of five repeated trials.
