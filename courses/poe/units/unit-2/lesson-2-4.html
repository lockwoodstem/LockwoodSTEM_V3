Lesson Targets

What You Will Be Able to Do

Learning Target

I can resolve an angled force into components and determine a resultant from perpendicular components.

Evidence

Vector component calculation

Success Looks Like

The sketch, signs, units, and calculated components agree with the stated angle convention.

Activity Flow

How the Lesson Moves

Each step builds the structural reasoning needed for the lesson deliverable.

1. Define the angle

Identify the reference axis and positive directions.

2. Resolve the vector

Use trigonometry to calculate perpendicular components.

3. Verify the result

Check signs, units, and whether the component magnitudes make sense.

Lesson Interactive

Resolve an Angled Support Force

Calculate the horizontal and vertical components of a 100 N force acting 30° above the positive horizontal axis.

Vector Diagram

Because the angle is measured from +x, the adjacent component uses cosine and the opposite component uses sine.

Enter the Components

Use Fₓ = F cos θ and Fᵧ = F sin θ with the stated axis directions.

Main Deliverable

Force-Vector Calculation

Resolve one assigned aerospace force vector.

  • Include a labeled vector diagram with axes, angle, magnitude, and component directions.
  • Show the component calculations with units and a reasonableness check.
