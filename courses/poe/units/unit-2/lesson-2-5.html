Calculating Force Vectors

Engineering question: How can we describe an angled force using horizontal and vertical components—and combine several forces into one resultant?

01 / Start with direction

A force is a vector, not just a number

A scalar has magnitude only (such as 100 kg of mass). A vector has magnitude and direction (such as a 100 N pull at 30° upward and to the right).

MagnitudeHow strong is the force? Measured in newtons (N); magnitude is never negative.
DirectionWhich way does it act? An angle must be measured from a clearly identified reference axis.
ComponentsHow much of that force acts along the x and y axes? These values can be positive, negative or zero.

Think before you calculate

Imagine a cable pulling a joint up and right. Do you expect both x and y components to be positive? What if the cable pulls down and right instead?

Check your prediction

Up/right gives +x, +y. Down/right gives +x, −y. The force magnitude stays positive; component signs tell us the direction.

Our angle convention

We measure θ counterclockwise from the positive x-axis, unless a problem explicitly says otherwise. A clockwise angle can be written as negative.

Calculator: Set the trig mode to DEG (degrees), not radians, for all problems on this page.

02 / Resolve one force

One diagonal force = two perpendicular components

To resolve means to replace one vector with horizontal and vertical vectors that add back to the original force.

Horizontal

The adjacent leg

Fₓ = F cos θ

Fₓ lies along the x-axis. For the drawn 30° force, cosine calculates the horizontal share.

Fₓ = 100 cos 30° ≈ +86.60 N

Vertical

The opposite leg

Fᵧ = F sin θ

Fᵧ lies along the y-axis. For the drawn 30° force, sine calculates the vertical share.

Fᵧ = 100 sin 30° = +50.00 N

Memory trick: COS = Adjacent / Hypotenuse; SIN = Opposite / Hypotenuse. The force F is the triangle's hypotenuse. These expressions assume θ is measured from +x; otherwise identify the adjacent and opposite legs first.
03 / Quadrants and signs

Direction tells you the sign

The same positive force magnitude can generate positive or negative components depending on which quadrant contains the vector.

Standard-angle convention: 0° points right, 90° points up, 180° points left, and −90° points down.

Examples using signed angles from +x

Angle θFₓFᵧ
+30°PositivePositive
+150°NegativePositive
−135°NegativeNegative
−60°PositiveNegative

Worked sign check: For 50 N at −60°, Fₓ = 50 cos(−60°) = +25.0 N; Fᵧ = 50 sin(−60°) = −43.30 N.

Angle measured from the vertical? If α is measured from the positive y-axis toward the positive x-axis in quadrant I, then Fₓ = F sin α and Fᵧ = F cos α. This is because horizontal is opposite α and vertical is adjacent α. Always sketch before choosing sine or cosine.

05 / Complete worked examples

Calculate, interpret, and verify

Follow the same method every time: sketch axes → identify θ → resolve → assign signs → check the result.

Example A · One force

100 N cable at +30°

  1. Draw: F points up/right. θ = +30° from +x.
  2. Calculate horizontal: Fₓ = (100)cos30° = +86.60 N.
  3. Calculate vertical: Fᵧ = (100)sin30° = +50.00 N.
  4. Check magnitude: √(86.60² + 50.00²) ≈ 100 N.
  5. Interpret: The cable's horizontal pull is larger than its upward pull.

F = (86.60 i + 50.00 j) N

Example B · Two forces

80 N @ +45° and 50 N @ −60°

ForceFₓ (N)Fᵧ (N)
F₁ = 80 N @ +45°+56.57+56.57
F₂ = 50 N @ −60°+25.00−43.30
Sum+81.57+13.27

Magnitude: R = √(81.57² + 13.27²) = 82.64 N.

Direction: θ = atan2(+13.27, +81.57) ≈ +9.24° above +x.

Intermediate values are rounded for display. Calculations use unrounded component values.

The complete resultant method

Rₓ = ΣFₓ  ·  Rᵧ = ΣFᵧ

Add only x components together; add only y components together. Never add magnitudes directly unless the vectors point along the same line in the same direction.

|R| = √(Rₓ² + Rᵧ²)

Calculate direction from the component signs and a quadrant-aware inverse tangent: θ = atan2(Rᵧ,Rₓ). If your calculator only has tan⁻¹, sketch the quadrant and correct the angle accordingly.

07 / Engineering application

Vectors inside a bridge truss

A diagonal truss member acts along its own axis. The force it exerts on a joint can be understood as an x force and a y force. This helps solve joint equilibrium in later Unit 2 lessons.

This diagram shows an example of a diagonal tension member pulling a lower joint up and right. A member in compression would exert a different force direction on that joint.

Example: 120 N member force at +35°

  1. Choose the joint where the diagonal attaches.
  2. Draw the member force along the diagonal, 35° above +x.
  3. Compute Fₓ = 120 cos35° = +98.30 N.
  4. Compute Fᵧ = 120 sin35° = +68.83 N.
  5. Interpret: the diagonal contributes both horizontal and vertical force at the joint.

Do not confuse components with extra forces: The x and y arrows are an equivalent representation of the original diagonal force. Do not count all three when summing forces.

08 / Independent practice

Calculate first, reveal answers second

Sketch axes and a force arrow for each problem. Use DEG mode, show trig setup, use signs and round final values to two decimals.

Check A · Fundamentals

75 N @ +60°

Find the signed horizontal and vertical components.

Reveal solution

Fₓ = 75 cos60° = +37.50 N. Fᵧ = 75 sin60° = +64.95 N. Both are positive in quadrant I.

Check B · Below horizontal

90 N @ −30°

Calculate Fₓ and Fᵧ. Which component is negative?

Reveal solution

Fₓ = 90 cos(−30°) = +77.94 N; Fᵧ = 90 sin(−30°) = −45.00 N. The force points down/right.

Check C · Quadrant II

40 N @ +150°

Find both components and verify their signs from a sketch.

Reveal solution

Fₓ = 40 cos150° = −34.64 N; Fᵧ = 40 sin150° = +20.00 N. The force points left/up.

Check D · Reverse the process

Fₓ = −30 N and Fᵧ = +40 N

Find magnitude and direction as a counterclockwise angle from +x.

Reveal solution

Magnitude = √(30² + 40²) = 50.00 N. Vector is in quadrant II: θ = atan2(+40, −30) ≈ +126.87°.

Check E · Sum two forces

80 N @ +45° and 50 N @ −60°

Calculate the resultant components, magnitude and direction.

Reveal solution

Rₓ = 56.57 + 25.00 = +81.57 N; Rᵧ = 56.57 − 43.30 = +13.27 N. |R| ≈ 82.64 N, θ ≈ +9.24°.

Check F · From the vertical

100 N at 20° to the right of +y

Explain whether sine or cosine gives the horizontal component. Then calculate both components.

Reveal solution

The angle is measured from +y, so horizontal is opposite: Fₓ = 100 sin20° = +34.20 N. Vertical is adjacent: Fᵧ = 100 cos20° = +93.97 N.

Vocabulary review

Resultant: a single vector with the same combined effect as several vectors.

Component: one perpendicular part of a force vector.

Quadrant: one of four regions of the xy-plane.

Resolve: express a vector as two perpendicular components.

Required evidence
