Main Deliverable

Aerospace Mechanism Systems Map

Create one systems map for an aerospace mechanism or rover subsystem.

  • Label the energy source, input motion, mechanism, and useful output.
  • Identify one testable performance measure such as lift force, travel distance, speed, or deployment time.
