Principles of Engineering • Unit 3

Rover Engineering & Robotics Fundamentals

Unit mission: Build one VEX V5 Clawbot rover progressively, test its drivetrain in tug-of-war, add an arm and claw, and qualify its movement and manipulation systems for Unit 4 autonomy.

VEX V5 Clawbot • Progressive Challenges

Build it. Program it. Test it. Improve it.

BuildCodeQualify

Keep the same VEX V5 robot throughout Units 3 and 4. Sensor-based navigation, feedback control and the final simulated planetary mission follow in Unit 4.

Development Plan

One Rover, Five Development Stages

3.1–3.6

Chassis & Drivetrain

Assemble standard Clawbot base only. Students may vary wheel type and drivetrain gear ratio. Do not attach arm or claw.

3.7

Tug-of-War

Use gearing, torque and traction evidence to explain match performance. No ballast, extra motors or claw.

3.8–3.10

Manual Control

Improve Python control, then complete Precision Driving Qualification.

3.11–3.14

Manipulation

Build the Clawbot arm and claw, program mechanisms and qualify sample retrieval.

3.15–3.18

Basic Autonomy

Program a route, qualify autonomous navigation, revise the rover and finish readiness testing.
