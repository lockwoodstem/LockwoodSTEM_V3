Activity Flow

How the Lesson Moves

Each step produces a decision, artifact, or test result needed for the capstone.

1. Decode the challenge

Identify the problem-solving, evidence, and presentation expectations.

2. Study strong evidence

Compare unsupported claims with tested and documented conclusions.

3. Set the project frame

Define an initial area of interest and realistic scope.

Capstone Scenario

A team wants to build an autonomous ground-support rover. Before selecting hardware, define what makes this an engineering capstone rather than a showpiece.

Goal: Select the four features that make the project meaningful, testable, and achievable.
