Problem Definition, Criteria & Constraints

Focus Question: How do engineers define the problem before designing a solution?

Opening Prompt

What happens when a team chooses a solution too early?

A preferred product can hide the real need and reduce the number of possible solutions.

Quick class share: What is the difference between “build a rocket stand” and “support a rocket safely during setup”?

Reveal the distinction

The problem describes the need. The solution is one possible response.

Good problem definition leaves room for multiple designs that can be compared against criteria and constraints.

Aerospace Context

Launch systems solve multiple connected needs

Observe the number of structures and interfaces surrounding the rocket.

Mindset Shift

Problem vs. Solution

Define the need before naming the final product.

Solution Too Early

“We are going to build a rocket stand.”

  • Names a product immediately
  • Can lock the team into one idea
  • Makes alternatives harder to compare
Problem Definition

“We need a way to support the rocket safely during setup.”

  • Explains the user and need
  • Leaves room for multiple solutions
  • Guides criteria and constraints
Core Vocabulary

Criteria, constraints, success, and evidence

Use these terms throughout the design challenge.

Criteria

Goals the design should meet.

Example: supports the rocket securely.

Constraints

Limits the design must follow.

Example: approved classroom materials only.

Success Criteria

How the team knows the design worked.

Example: does not tip during the stability test.

Evidence

Proof used to justify decisions.

Example: sketches, photos, data, and observations.
Classification Challenge

Criterion or constraint?

Classify each statement before opening the answer.

A. The launch pad must fit the provided rocket.

B. The design should include a realistic access feature.

C. Teams may use only approved classroom materials.

D. The prototype should stand without tipping.

Reveal the classification

Criteria

B and D describe performance goals.

Constraints

A and C establish required limits or conditions.

A statement may function differently in another project. Classification depends on how the challenge is written.
Activity

Define before brainstorming

Complete the worksheet without selecting a final solution too early.

  1. Read the scenario carefully.
  2. Identify the user, need, and reason.
  3. Write the problem in one or two clear sentences.
  4. List criteria the design should meet.
  5. List constraints that limit the design.
  6. Check that the statement does not assume one final solution.
