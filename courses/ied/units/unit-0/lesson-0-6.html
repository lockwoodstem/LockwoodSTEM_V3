OPENING PROMPT

What problem are we actually solving?

  • Use this as a quick class discussion while attendance is taken.
  • Think first. Why does problem definition matter in engineering work?
  • Quick class share
  • Raise your hand and share one way problem definition could improve a project.
  • Student answers might include: clearer decisions, better tests, stronger evidence, or better communication.
  • We will reveal a working definition on the next slide.
Reveal answer / debrief

OPENING DEBRIEF

  • Problem Definition
  • A working definition for this lesson.
  • Problem Definition helps engineers make work clear, testable, and defendable.
  • Clarify
  • Make the goal and evidence easier to understand.
  • Plan
  • Decide what should happen before building.
  • Check
  • Use criteria, data, or feedback to judge the work.
  • Explain
  • Communicate the decision with evidence.
  • Today's mission: practice problem definition so the next design step is stronger.

Slide 9

MINDSET SHIFT

Problem vs. Solution

  • The goal is to make engineering thinking visible and useful.
  • Solution too early
  • Weak approach
  • Unclear purpose
  • Little evidence
  • Hard to inspect
  • Difficult to revise
  • Clear problem definition
  • Strong approach
  • Clear purpose
  • Evidence is recorded
  • Easy to inspect
  • Supports revision

MINI CHALLENGE

What Best Defines the Problem?

  • Read the claim. Select the two strongest supports.

  • Vote for the two strongest supports.
  • A
  • It states a need without choosing one solution
  • B
  • It says to build a rocket stand immediately
  • C
  • It leaves room for multiple designs
  • D
  • It ignores criteria and constraints
  • E
  • It focuses only on decoration
  • Vote first. Then we will reveal the best evidence pair.

EVIDENCE REVEAL

  • What Best Defines the Problem?
  • The best support connects directly to the claim.
  • Best support: A + C
  • A
  • It states a need without choosing one solution
  • The problem is defined before a product is chosen.
