Launch Pad Testing & Improvement

Focus Question: How does testing show what a prototype needs next?

View Lesson Plan What You Submit Back to Unit 0
Mission Objective

Turn tests into improvements

Test the launch pad against the challenge criteria, record specific results, revise one weakness, and retest.

TestRecordRevise
Mission Briefing

45-Minute Flight Plan

Run criterion-based tests and use the results to guide a documented design change.

Learning Targets

  • Test the prototype against challenge criteria.
  • Record observations, strengths, weaknesses, and failure points.
  • Make at least one evidence-based improvement.

Success Looks Like…

You can connect one design improvement directly to a test result.

Core habit: A test result should lead to a clear decision: keep, change, or investigate.

Opening Prompt

What makes a test useful?

A test should answer a specific question connected to a design requirement.

Quick class share: What is the difference between “try it” and “test it”?

Reveal the testing standard

A useful test has a criterion, a repeatable action, and evidence to record.

The result should guide a clear next decision.

Aerospace Context

Testing happens before commitment

Real launch systems are checked as integrated structures, not only as separate parts.

Test Criteria

Match each test to a requirement

Record what actually happens—not what the team hoped would happen.

Stability Test

Does the pad stand without tipping?

Record: pass/fail, wobble, tipping direction, photo.

Rocket Fit Test

Does the provided rocket sit securely?

Record: contact points, slipping, movement, alignment.

Support Test

Does the structure hold without bending or collapsing?

Record: weak joints, bending, sliding, deformation.

Feature Check

Can the team explain the function of realistic launch-pad features?

Record: labels and functional explanation.

Improvement Options

Choose changes that address test results

Do not add parts without a reason.

  • Widen the base to improve stability.
  • Reinforce weak joints or support columns.
  • Adjust rocket-support spacing or angle.
  • Add bracing to reduce bending or twisting.
  • Improve alignment so the rocket sits securely.
  • Remove parts that add weight without function.
Scenario Response

The pad holds the rocket but wobbles

Choose the strongest next step before opening the answer.

  1. AKeep it because it did not fall.
  2. BAdd realistic-looking details.
  3. CRecord the wobble, locate the weak area, revise the base or supports, and retest.
  4. DRepeat the same test without recording anything.
Reveal the evidence-based next step

Best answer: C

The wobble is a specific weakness. The team should record it, target the likely cause, and collect new evidence after revision.
