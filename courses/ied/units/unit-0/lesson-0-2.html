Opening Prompt

What makes a notebook useful later?

Think beyond neatness: what must another person be able to find or understand?

Quick class share: Name one piece of engineering evidence that would be difficult to recreate if it were not recorded.

Reveal the working definition

An engineering notebook is a chronological evidence record.

It captures what happened, when it happened, and why decisions changed so the work can be reviewed, repeated, or improved.

Notebook System

Build the binder in the correct order

The table of contents is the map; numbered documents are the evidence trail.

Binder Setup

Required structure

  1. Place the printed Table of Contents first.
  2. Do not number the Table of Contents.
  3. Start page numbering with the first actual document.
  4. Add new work in the order it is completed.
  5. Update the Table of Contents as documents are added.
Why It Matters

Professional habits

  • Makes design thinking visible
  • Helps teams trace decisions
  • Creates evidence for design reviews
  • Supports revision and inspection
  • Prevents lost or disconnected work

File Naming

Make digital work findable

A useful name should make sense before the file is opened.

Required format: LastName_FirstName_Unit_AssignmentName

Which name is stronger?

  1. 1finalfinal2.pptx
  2. 2Lockwood_Jonathan_Unit0_PaperAirplaneEvidence.pptx
Reveal the stronger file name

Best answer: 2

It identifies the student, unit, and assignment without opening the file. Avoid vague names such as final, new, or thing.

Check: Save files in the correct location and keep a backup when work is important.
