Dimensioning Basics

Focus question: How do engineers show the size of an object clearly in a drawing?

Mission Focus

Add size and location information so a drawing can guide fabrication or inspection.

Mission Briefing

Today’s Plan

Use this page with the lesson presentation and your engineering notebook.

Learning Targets

  • Identify the dimensions needed to define overall size and feature location.
  • Use dimension lines, extension lines, arrowheads, and symbols correctly.
  • Audit a drawing for missing, duplicated, or ambiguous dimensions.

Success Looks Like

Another person can determine the required sizes without measuring the drawing itself.

Opening Prompt

Why is a perfectly drawn shape still incomplete without dimensions?

Think first, then be ready to share a short response that connects the question to engineering communication.

Reveal: why this matters

The views communicate shape, but dimensions communicate the required size and feature locations. Without them, a fabricator would have to guess or scale the picture.

Core Skill

What We Are Practicing

Key Idea 1

Views communicate shape; dimensions communicate size and location.

Key Idea 2

Dimension lines, extension lines, arrows, symbols, and values work together.

Key Idea 3

Good dimensioning is complete without repeating the same information.

Your Task

Dimension a Part for Manufacturing

Add a complete but nonredundant set of dimensions to a provided technical drawing.

  1. Identify the overall sizes and the information needed to locate each feature.
  2. Place extension and dimension lines outside the object whenever possible.
  3. Use diameter and radius symbols correctly for circular and curved features.
  4. Audit the drawing for missing, duplicated, crossed, or ambiguous dimensions.

Quality check: Every required size and location must be stated once, and no information should depend on scaling the drawing.

What You Will Submit

Fully Dimensioned Technical Drawing

Submit one completed drawing and one audit note.

  • One technical drawing with complete, correctly placed overall and feature dimensions.
  • One short audit note identifying a missing or duplicate dimension that was corrected.

Submission standard: Use one unit system consistently and do not place a dimension value on an object line.
