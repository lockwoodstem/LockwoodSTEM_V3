IED Unit 1 • Project 1.8 • Multi-day project

Engineering Documentation Challenge

Focus question: Can you accurately document a real manufactured object so another engineer can understand and inspect it without guessing?

Download TemplatesView DeliverablesBack to Unit 1
Final Unit Challenge

Select and document your own manufactured object using sketching, measurement, multiview drawing, dimensioning, tolerances, and engineering review.

DocumentVerifyImprove

Success: Your approved object is documented clearly enough that another student can understand its geometry, important dimensions, features, and manufacturing details without a verbal explanation.

Project Overview

Document an Object You Select

You will provide a real manufactured object, qualify it for the project, measure it, and create a complete engineering documentation package. The project is divided into checkpoints so each part is reviewed before you move forward.

Learning Targets

  • Select appropriate views to communicate a physical object.
  • Create accurate isometric and aligned multiview sketches.
  • Use object, hidden, and center lines correctly.
  • Measure features with appropriate tools and precision.
  • Apply clear, non-redundant dimensions.
  • Identify dimensions where tolerance or fit matters.
  • Produce technical documentation that another person can interpret without verbal explanation.

Final Goal

Your completed package should communicate the shape, size, location, and important features of your object using the engineering documentation skills developed throughout Unit 1.

Before the Project

Choose Your Object

You are responsible for bringing an object that meets the requirements below. Do not begin detailed drawings until your object has been approved.

Size

Easy to Handle

The object must fit completely inside a 6 × 6 × 6 inch envelope and be rigid enough to measure repeatedly.

Geometry

Enough Complexity

It must contain at least three distinct geometric features such as holes, slots, steps, curves, fillets, chamfers, bosses, recesses, or cylindrical features.

Views

Meaningful Multiviews

The front, top, and right-side views must communicate useful and meaningfully different information.

Features

Technical Drawing Evidence

Include straight or planar geometry plus at least one curved or circular feature and at least one feature that benefits from a centerline, hidden line, or symmetry indication.

Measurement

Measurable

The object must allow meaningful measurements with classroom rulers and/or calipers and should require roughly 8–15 dimensions to describe its important geometry.

Appropriate

Safe and Practical

The object must be clean, school-appropriate, nonvaluable, and safe to handle. Avoid soft/flexible objects, highly irregular freeform shapes, transparent objects, or extremely simple objects such as a plain block, ball, washer, bottle, or pencil.

Assemblies are allowed but not required. If your object contains multiple parts, you may also document an important interface or joining method.

Project Checkpoints

Turn In the Project in Stages

Each deliverable is submitted separately. Feedback from one checkpoint should be used before beginning or finalizing the next.

Deliverable 1

Object Qualification & Approval

Turn in: object identification, approximate overall dimensions, feature inventory, proposed front view, and teacher approval.

  • Bring the physical object to class.
  • Verify the 6 × 6 × 6 in. limit.
  • Identify at least three geometric features.
  • Explain why the object will produce useful front, top, and right-side views.

Checkpoint: Your object must be approved before continuing.

Deliverable 2

Object Analysis & Isometric Sketch

Turn in: labeled object analysis and a clean isometric sketch.

  • Identify major features, symmetry, curves, holes, slots, or other geometry.
  • Establish the intended orientation.
  • Create an isometric overview showing the complete object.
  • Label important features that will need measurement.
Deliverable 3

Measurement & Inspection Record

Turn in: completed measurement table.

  • Record the dimensions needed to describe the object.
  • Identify the measuring tool used for each measurement.
  • Record values using appropriate precision.
  • Identify several dimensions that are especially important to fit, alignment, or function.
Deliverable 4

Multiview Technical Drawing

Turn in: front, top, and right-side views with technical line conventions.

  • Keep views aligned.
  • Use object, hidden, and center lines correctly.
  • Show circular, symmetric, and hidden features appropriately.
  • Add the dimensions needed to size and locate important features without unnecessary duplication.
Deliverable 5

Tolerance & Documentation Review

Turn in: critical-dimension analysis plus peer review.

  • Select important dimensions and propose reasonable tolerances.
  • Explain why tighter or looser control matters.
  • Have another student review the documentation without using the physical object as an explanation.
  • Record unclear or missing information and make revisions.
Deliverable 6

Final Engineering Documentation Package

Turn in: the revised complete package.

  • Approved object qualification.
  • Final isometric sketch.
  • Measurement record.
  • Dimensioned multiview drawing.
  • Tolerance analysis.
  • Peer-review revisions.
  • Short final reflection on the hardest information to communicate and how you solved it.
Submission Rule

Do Not Wait Until the End

This project is graded through multiple submissions. A later deliverable does not replace a missed earlier checkpoint. Keep every returned checkpoint because the corrected work becomes part of your final documentation package.

Final Package

What the Completed Project Must Show

  • An approved student-selected manufactured object.
  • Accurate isometric and aligned front, top, and right-side views.
  • Correct technical line conventions.
  • Actual measurements recorded with appropriate tools and precision.
  • Clear, non-redundant size and location dimensions.
  • Critical-dimension and tolerance reasoning.
  • Evidence of peer review and revision.
  • A concise final reflection.

Engineering rule: If another student must guess, ask, or assume something important about the object, the documentation is not finished.
