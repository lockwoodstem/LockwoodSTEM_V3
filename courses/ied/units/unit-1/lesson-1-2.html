Line Conventions

Focus question: How do different types of lines help engineers communicate clearly?

Mission Briefing

45-Minute Flight Plan

Learning Targets

  • Explain why engineering drawings use standardized line patterns.
  • Identify visible edges and hidden features in a selected view.
  • Use consistent solid and dashed line patterns in a drawing.

Success Looks Like

The line pattern alone clearly distinguishes visible edges from hidden features.

LaunchLearnApplyCheckSubmit
Opening Prompt

Why might a dashed line communicate something different from a solid line?

Think first, then be ready to share a short response that connects the question to engineering communication.

Reveal: why this matters

Engineering line patterns act like a visual code. A solid line can show an edge that is directly visible, while a dashed line can show an important feature hidden behind a surface.

Core Skill

What We Are Practicing

Key Idea 1

Line conventions are standardized visual signals used in technical drawings.

Key Idea 2

Solid object lines show edges that are directly visible from the selected view.

Key Idea 3

Dashed hidden lines show important features that are blocked by another surface.

Student Task

Compare Visible and Hidden Edges

Use the Lesson 1.2 model and reference views to study how the same part changes when viewed from different directions. Focus only on visible object lines and dashed hidden lines.

  1. Choose one standard view and compare it with the 3D model.
  2. Trace or redraw the view using solid lines for visible edges and dashed lines for hidden features.
  3. Create a two-item key labeling the object-line and hidden-line patterns.

Quality check: Every line should match a real edge or feature in the selected view, and the two patterns must be easy to distinguish.

Student Deliverables

Visible-and-Hidden-Line Study

Submit a focused comparison using only the line conventions introduced in this lesson.

  • One labeled standard-view drawing using correct object and hidden lines.
  • A two-sentence note identifying one visible edge and one hidden feature in the drawing.

Submission standard: Use only the solid and dashed line patterns practiced in this lesson, and keep each pattern consistent.
