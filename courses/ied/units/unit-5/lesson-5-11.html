Core Skill

What We Are Practicing

Key Idea 1

A testing protocol makes evaluation fair, repeatable, and useful.

Key Idea 2

User feedback should connect to user needs and design criteria.

Key Idea 3

Good tests measure the claim the team wants to make.

Your Task

Design the Test and User Feedback Plan

Create a fair performance test and a respectful feedback method that directly address the user needs and design criteria.

  1. Select the criteria and user questions to evaluate.
  2. Define measures, success thresholds, and trial conditions.
  3. Write repeatable test steps and prepare the data table.
  4. Prepare neutral user-feedback questions and consent/privacy expectations as appropriate.

Quality check: Every test or feedback question produces evidence tied to a criterion or user need.
