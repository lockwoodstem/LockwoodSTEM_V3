Core Skill

What We Are Practicing

Key Idea 1

Integration is where separate parts become a system.

Key Idea 2

Refinement should focus on readiness for testing, not just appearance.

Key Idea 3

A prototype is test-ready when the team can explain what will be evaluated and why.

Student Task

Integrate and Refine the Prototype

Complete subsystem integration, improve usability and reliability, and prepare the design for formal testing.

  1. Complete remaining assembly and subsystem connections.
  2. Check fit, movement, access, and user interaction.
  3. Correct obvious safety or reliability problems.
  4. Identify what is ready for testing and what remains limited.

Quality check: The prototype can be tested safely and the team can state its current operating limits.

Lesson Interactive

Resolve Prototype Integration Problems

Match each interface problem to a corrective action, then identify the issue that must be handled first.

Integration issueBest corrective action
A wire flexes sharply where it enters the moving housing.
The linkage rubs the frame near the end of travel.
A fastener cannot be reached after the cover is installed.
Correct the cause of each interface problem and prioritize user safety before appearance.
