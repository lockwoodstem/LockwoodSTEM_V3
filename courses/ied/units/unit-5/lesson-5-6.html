Core Skill

What We Are Practicing

Key Idea 1

A decision matrix makes concept selection more transparent.

Key Idea 2

Scores should connect to criteria, not popularity.

Key Idea 3

The best concept is the one that best fits the defined problem and constraints.

Your Task

Select the Capstone Concept with Evidence

Use weighted criteria and research evidence to compare the concepts and choose a defensible direction.

  1. Confirm that the matrix criteria match the design brief.
  2. Set and justify criterion weights.
  3. Score each concept using known evidence.
  4. Select the concept and document uncertainty or needed proof.

Quality check: The selected concept is supported by the matrix and the justification acknowledges weak evidence or risk.

Lesson Interactive

Select a Concept with a Weighted Decision Matrix

Weights represent criterion importance. Calculate each concept’s weighted total, then select the highest-scoring concept.
