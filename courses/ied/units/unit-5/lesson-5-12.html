Core Skill

What We Are Practicing

Key Idea 1

Testing should reveal the truth, not prove the team was right.

Key Idea 2

User feedback can show needs that performance data may miss.

Key Idea 3

Honest evidence makes revision stronger.

Student Task

Collect Prototype and User Evidence

Run the approved tests and feedback activities while recording results, observations, comments, and limitations accurately.

  1. Complete the setup and safety check.
  2. Run the planned performance trials.
  3. Collect feedback without leading the participant.
  4. Record unexpected results and limitations without deleting unsuccessful evidence.

Quality check: The evidence is complete, ethically collected, and traceable to the approved plan.
