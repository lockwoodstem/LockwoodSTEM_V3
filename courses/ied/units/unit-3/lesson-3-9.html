Assignment

Prepare Rocket Components for Prototype Printing

Use the verified Lesson 3.8 assembly to create the manufacturing files needed for the physical prototype. Do not export reference-only or non-printed components.

Step-by-Step Instructions

  1. Identify printable components: Use the project requirements to determine exactly which rocket parts must be manufactured.
  2. Confirm final versions: Make sure the selected components match the verified assembly and do not come from older design copies.
  3. Check printability: Identify a practical flat-face orientation and verify that each part can be printed using the class manufacturing expectations.
  4. Export each component: Create one STL file per required printed component using Save as Mesh/Export Mesh.
  5. Name every file: Include the component name and revision/version when required by the instructor.
  6. Review the exports: Confirm that each STL contains only the intended component and is at the correct scale.
  7. Submit for printing: Upload the final manufacturing set to the assigned location. Follow the instructor's batch-printing process rather than independently starting a printer unless directed.

Before You Submit

  • Only final, required components are exported.
  • Each STL contains one intended component.
  • Files use clear names.
  • Scale and orientation are appropriate.
  • The exported files correspond to the verified Lesson 3.8 assembly.
Submission

What You Will Submit

  • Manufacturing package: all required rocket STL files using the class naming convention.
  • Final assembly archive: the matching verified .f3d file.
  • Export screenshot: show the final assembly and the components selected for printing.

Unit 2 connection: This lesson applies the STL/export workflow you already used for the Puzzle Cube; the new emphasis is configuration control across an assembly.
