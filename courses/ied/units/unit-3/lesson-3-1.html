IED Unit 3 • Lesson 3.1

From Bodies to Components & Assemblies

Focus question: What changes when an engineer moves from separate bodies to a true CAD assembly?

Go to AssignmentWhat to SubmitBack to Unit 3
Assembly Foundations

Use your Unit 2 experience to understand bodies, components, origins, and assembly structure.

Expected result: A clean Fusion file that demonstrates the difference between bodies and components without repeating the Puzzle Cube project.

Lesson Overview

What You Are Learning

Learning Targets

  • Distinguish a body from a component in Fusion.
  • Convert existing bodies into separately managed components.
  • Use names, origins, and grounding to create an organized assembly structure.
  • Explain assembly organization through the Fusion Browser rather than by visual appearance alone.

Unit 3 Progression

Unit 2 ended with five separate bodies in one Puzzle Cube design. Unit 3 begins by turning that familiar idea into a true component-based assembly workflow.

Assignment

Convert a Multi-Body Design into an Assembly Structure

Use a copy of your Puzzle Cube design or the teacher-provided practice file. The goal is not to redesign the puzzle; it is to learn what components add to an assembly workflow.

Step-by-Step Instructions

  1. Save a copy first: Open the practice multi-body design and save a new copy so the Unit 2 submission remains unchanged.
  2. Inspect the Browser: Identify the root design, bodies, sketches, and origins. Confirm that the puzzle pieces are currently separate bodies.
  3. Create components from the bodies: Convert each puzzle body into its own component using the demonstrated Fusion workflow.
  4. Rename the components: Use clear names such as Piece A–E or the naming convention provided by the instructor.
  5. Inspect component origins: Expand at least two component Origin folders and compare them with the root origin.
  6. Ground one component: Ground the component identified by the instructor and verify that it cannot be freely dragged.
  7. Move a different component: Move an ungrounded component and observe how component motion differs from editing body geometry.
  8. Restore the assembly: Return all pieces to the correct assembled position and save the file.

Before You Submit

  • The Browser shows separate components rather than only bodies.
  • Each component has a clear name.
  • The designated component is grounded.
  • The puzzle is returned to its assembled position.
  • The original Unit 2 file was not overwritten.
Submission

What You Will Submit

  • Fusion archive: component-based practice design exported as LastName_FirstName_3_1_Components.f3d.
  • Browser screenshot: show the assembled model with the five named components and the grounded component visible.

Carryover from Unit 2: You are reusing familiar geometry so the new learning can focus entirely on component and assembly organization.
