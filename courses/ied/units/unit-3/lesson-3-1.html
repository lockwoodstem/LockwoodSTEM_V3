IED Unit 3 • Lesson 3.1

Revolute Joints & Rotational Motion

Focus question: How can a joint allow one component to rotate while keeping the rest of an assembly constrained?

Go to AssignmentWhat to SubmitBack to Unit 3
Motion Foundations

Build a functioning hinged bracket from teacher-provided parts and introduce revolute joints.

Expected result: A correctly constrained hinge whose arm pivots while the base remains stationary.

Lesson Overview

What You Are Learning

Learning Targets

  • Apply previously learned rigid joints to stationary components.
  • Create a revolute joint with a correctly located pivot axis.
  • Ground the base and test the remaining degrees of freedom.
  • Demonstrate that the pivot arm rotates without coming loose.

Unit 3 Progression

You already made a Puzzle Cube assembly using rigid joints in Unit 2. This lesson introduces controlled motion—not another body-to-component exercise.

Assignment

Hinged Bracket: Revolute Joint Challenge

Use the teacher-provided individual Fusion parts: 1 base bracket, 1 pivot arm, 1 pivot pin, 2 spacers, and 1 retaining cap. Do not remodel the parts.

Step-by-Step Instructions

  1. Create a new Fusion design named LastName_FirstName_3_1_Hinge and insert all six supplied parts as components.
  2. Ground the base bracket and rename every component clearly in the Browser.
  3. Assemble stationary hardware with the rigid-joint skills learned in Unit 2.
  4. Create a revolute joint about the correct pivot axis so the arm rotates relative to the grounded bracket.
  5. Drag or Drive Joint to test rotation; correct any unwanted translation or detached parts.
  6. Save the completed assembly and record a short demonstration with the base visible.

Before You Submit

  • Exactly six supplied parts are present (including two spacers).
  • The base remains fixed; the arm rotates about the correct pin axis.
  • No component slides away or moves independently unless intentionally designed.
Submission

What to Submit

Upload the following specific items to the Lesson 3.1 assignment in Google Classroom:

  • Fusion file (.f3d): export the completed hinge assembly as LastName_FirstName_3_1_Hinge.f3d. The base must be grounded and revolute/rigid joints saved.
  • Motion recording (.mp4, 10–20 seconds): show the assembled hinge in Fusion, move the arm through its available rotation, and demonstrate that the grounded base does not move.

Submission check: Submit the actual working assembly—not a screenshot of an unassembled parts kit.
