IED Unit 3 • Lesson 3.3

Placing & Positioning Components

Focus question: How can components be positioned accurately before permanent assembly relationships are applied?

Go to AssignmentWhat to SubmitBack to Unit 3
Assembly Foundations

Place the major rocket components in a logical assembled orientation without relying on visual guessing.

Expected result: A complete rough-positioned rocket assembly ready for joints.

Lesson Overview

What You Are Learning

Learning Targets

  • Use Move/Copy and Align appropriately for initial component placement.
  • Use origins, faces, edges, and axes as controlled references.
  • Recognize the difference between temporary placement and an assembly relationship.
  • Verify orientation before creating joints.

Unit 3 Progression

The file structure from Lesson 3.2 becomes a working assembly as components are placed relative to the grounded reference.

Assignment

Create the Initial Rocket Assembly Layout

Position the rocket components so the overall assembly is understandable and ready for joints. This lesson is about controlled placement—not final fit verification.

Step-by-Step Instructions

  1. Open the master assembly: Confirm the correct component list and grounded reference component.
  2. Place the primary axial parts: Position the nose, body, couplers, base/nozzle, or other assigned axial components using faces, centers, and axes as references.
  3. Orient each component: Rotate components so their intended mating faces point in the correct direction.
  4. Use Align when appropriate: Align cylindrical or planar features rather than estimating their position by eye.
  5. Place repeated parts: Position fins or other repeated components in their approximate intended locations without final symmetry relationships yet.
  6. Check the overall orientation: Use front, top, right, and isometric views to confirm no component is flipped or rotated incorrectly.
  7. Save the positioned assembly: Preserve this initial layout before creating joints in Lesson 3.4.

Before You Submit

  • Major components are in the correct order and orientation.
  • No component was positioned only by visual guessing when a reference was available.
  • The grounded reference remains fixed.
  • The overall rocket reads correctly in standard views.
Submission

What You Will Submit
