IED Unit 3 | Mission Brief 3.2

Portfolio-Quality Exploded View

Create a professional exploded view, BOM, and assembly-order visual suitable for a portfolio or design review.

Intermediate1-2 class periodsSkill Builder
Back to Challenge HubDownload Challenge Brief (PDF)
Engineering Design Brief

Work independently or with an approved partner.

Read the complete brief before gathering materials or beginning construction.

Background

Engineering Context

A technical presentation needs one image that clearly explains how the rocket assembly fits together.

Objectives

What You Will Practice

  • Create an exploded assembly view
  • Use balloons and a BOM consistently
  • Communicate assembly sequence
  • Improve technical drawing layout
Materials

What You Need

  • Completed rocket assembly CAD
  • Fusion 360 drawing workspace
  • Drawing checklist
  • Engineering notebook
Procedure

Student Instructions

  1. Inspect the assembly browser and rename unclear components.
  2. Create or verify a complete BOM with part numbers and quantities.
  3. Plan an explosion direction that keeps parts readable and avoids crossing paths.
  4. Create the exploded view with consistent spacing.
  5. Add trail lines where they clarify movement.
  6. Place the view on a drawing sheet and add balloons linked to the BOM.
  7. Add one detail view for a small or hidden connection.
  8. Use the checklist to inspect alignment, readability, title block, and consistency.
Requirements

Engineering Requirements

  • Every modeled component appears in the BOM
  • Every BOM item is ballooned exactly once in the main view or detail
  • Explosion order reflects a logical assembly sequence
  • No part paths overlap in a confusing way
  • Drawing includes title, scale, revision, and author
Constraints

Constraints & Safety

  • Use the current approved assembly
  • Keep the drawing to one sheet
  • Do not use decorative backgrounds that reduce readability
Deliverables

What You Submit

  • Updated assembly component names
  • Exploded view drawing PDF
  • BOM
  • Ballooned assembly view
  • One detail view
  • Completed quality checklist
Reflection

Reflection Questions

  1. Which parts were hardest to separate visually?
  2. How did you choose the explosion direction?
  3. Could a technician infer assembly order?
  4. What makes the drawing portfolio-ready?
Download PDF
Engineering Tip

Use larger spacing for large parts and smaller spacing for closely related fasteners, but keep the pattern consistent.

Common Mistake

An exploded view is not random separation. It should preserve relationships and communicate sequence.

Stretch Goal

Create a short animation that follows the same assembly order.

Career Connection

Technical illustrators and mechanical designers create exploded views for assembly, service, sales, and training.

Before You Submit
  • Notebook evidence included
  • Requirements checked
  • Testing documented
  • Reflection completed
