IED Unit 3 • Lesson 3.2

Components & Assembly File Organization

Focus question: How do engineers organize multiple CAD parts so an assembly remains understandable and editable?

Go to AssignmentWhat to SubmitBack to Unit 3
Assembly Foundations

Create the controlled file structure that will be used for the Unit 3 rocket assembly project.

Expected result: A correctly named and organized rocket assembly file ready for component placement.

Lesson Overview

What You Are Learning

Learning Targets

  • Create a dedicated assembly design and project location.
  • Insert or create rocket parts as components rather than loose bodies.
  • Use clear component names and avoid ambiguous duplicates.
  • Establish a logical grounded reference component for the assembly.

Unit 3 Progression

Now that you understand components, you will apply the same structure to the rocket project that continues through the rest of Unit 3.

Assignment

Build the Rocket Assembly File Structure

Create the master Fusion design that will hold the rocket assembly. Use the teacher-provided rocket parts, reference geometry, or assigned part files.

Step-by-Step Instructions

  1. Create the master assembly: Start a new Fusion design in the correct class project/folder and save it using the required assembly filename.
  2. Identify the required parts: Review the instructor-provided rocket part set and confirm which parts will be inserted, reused, or modeled later.
  3. Insert parts as components: Bring the required parts into the assembly using the demonstrated workflow. Do not paste them in as anonymous bodies.
  4. Rename every component: Use descriptive names that identify the actual rocket part. Remove generic names such as Body1 or Component2.
  5. Check units and origins: Confirm the imported parts use the correct units and that their component origins are available.
  6. Remove accidental duplicates: Verify that repeated parts are intentional. Delete or suppress duplicate inserts that are not part of the design.
  7. Choose the assembly reference: Ground the primary body or other instructor-designated reference component.
  8. Save before positioning: Save the organized assembly before beginning detailed placement in Lesson 3.3.

Before You Submit

  • The file is stored in the correct project/folder.
  • All inserted parts appear as components.
  • Component names are clear and unique where appropriate.
  • The correct reference component is grounded.
  • No unexplained duplicate parts are present.
Submission

What You Will Submit

  • Fusion archive: organized rocket assembly file exported as LastName_FirstName_3_2_RocketAssembly.f3d.
  • Browser screenshot: show the component hierarchy and grounded reference component.
