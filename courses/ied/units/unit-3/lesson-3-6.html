Rocket Assembly Challenge

Define the rocket assembly requirements and create a clear plan before major CAD revisions begin.

Expected result: An approved assembly plan identifying components, interfaces, required revisions, and manufacturing needs.

Lesson Overview

What You Are Learning

Learning Targets

  • Interpret the rocket assembly requirements as a system.
  • Identify provided, reused, and student-modified components.
  • Map component interfaces before changing geometry.
  • Plan symmetry, assembly order, and manufacturing needs.

Unit 3 Progression

Lessons 3.1–3.5 taught the assembly tools. The remainder of Unit 3 applies those tools to a complete rocket assembly design challenge.

Assignment

Plan the Unit 3 Rocket Assembly

Review the challenge requirements and your current assembly. Build a plan that identifies what already works and what must be created or revised.

Step-by-Step Instructions

  1. Review the challenge requirements: Identify every required component, interface, symmetry requirement, and manufacturing constraint provided by the instructor.
  2. Audit the current assembly: Mark each component as Ready, Needs Revision, Needs Modeling, or Provided/Reference.
  3. Create an interface map: Identify which components connect to one another and the geometry that controls each connection.
  4. Plan fin or repeated-part symmetry: Determine how repeated parts will be positioned consistently around the rocket body.
  5. Identify manufacturing parts: Note which components are expected to be 3D printed and which are represented by existing classroom materials or hardware.
  6. Plan assembly order: Determine a logical order for inserting, joining, or placing the major components.
  7. Get the plan checked: Confirm the project plan with the instructor before making large geometry changes.

Before You Submit

  • Every required component is accounted for.
  • Interfaces are identified before geometry changes begin.
  • Repeated parts have a symmetry/placement plan.
  • Manufacturing needs are identified.
  • The plan is approved before the CAD workday.
Submission

What You Will Submit

  • Assembly plan: component audit and interface map using the instructor-provided format or engineering notebook.
  • Planning screenshot: current assembly with components visible and clearly named.
