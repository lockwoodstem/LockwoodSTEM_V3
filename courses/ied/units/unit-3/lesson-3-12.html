IED Unit 3 • Lesson 3.12

Assembly Drawing & Exploded Documentation

Focus question: How does an assembly drawing communicate information that a part drawing cannot?

Go to AssignmentWhat to SubmitBack to Unit 3
Documentation

Extend Unit 2 drawing skills into professional multi-component assembly documentation.

Expected result: An assembly drawing package that identifies every component and communicates how the rocket fits together.

Lesson Overview

What You Are Learning

Learning Targets

  • Apply existing drawing-view skills to a complete assembly.
  • Create an exploded assembly view that communicates component relationships.
  • Use balloons and a parts list/BOM consistently.
  • Add useful assembly notes and revision information.

Unit 3 Progression

Unit 2 introduced drawing views and exploded presentation. Unit 3 adds true assembly documentation: item identification, parts lists, notes, and revisions.

ComponentsAssembleVerifyPrototypeReviseDocument
Assignment

Create the Rocket Assembly Drawing

Use the final revised assembly from Lesson 3.11. The goal is not to repeat the Puzzle Cube drawing; it is to create documentation that could guide another person through the assembly.

Step-by-Step Instructions

  1. Start the assembly drawing: Create a Fusion drawing from the final revised rocket assembly using the assigned sheet standard.
  2. Add the assembled views: Place the minimum orthographic/isometric views needed to communicate the overall rocket.
  3. Create an exploded representation: Use an appropriate Fusion workflow to create or capture a clear exploded arrangement while preserving the original final assembly.
  4. Add an exploded view to the documentation: Make sure all major components can be distinguished.
  5. Create the parts list/BOM: Include item number, component/part name, quantity, and any additional instructor-required information.
  6. Add balloons: Balloon the exploded/assembly view so every item number matches the parts list.
  7. Add assembly notes: Include only information needed to understand fit, orientation, assembly sequence, or manufacturing details.
  8. Add revision information: Identify the current revision and the change documented in Lesson 3.11.
  9. Check readability: Make sure views, balloons, parts list, and notes do not overlap and can be read at normal page scale.
  10. Export the drawing: Save the completed documentation as PDF.

Before You Submit

  • The assembly is shown clearly.
  • The exploded view communicates component relationships.
  • Every balloon matches the parts list/BOM.
  • Quantities and part names are correct.
  • Assembly notes add useful information.
  • Revision information matches the final CAD assembly.
Submission

What You Will Submit

  • Assembly drawing PDF: exported as LastName_FirstName_3_12_RocketAssemblyDrawing.pdf.
  • Exploded-view image: clear exploded assembly image if not already clearly represented in the PDF.
  • Final Fusion assembly: keep available for the final design package.
