Core Skill

What We Are Practicing

Key Idea 1

Joints define how parts relate to one another.

Key Idea 2

The wrong joint can create hidden alignment or motion errors.

Key Idea 3

Relationships should match the physical design intent.

Student Task

Define Assembly Relationships with Joints

Add appropriate joints so parts remain connected and behave according to the intended assembly relationship.

  1. Choose the two components and joint locations.
  2. Select the joint type that matches the intended relationship.
  3. Set alignment, orientation, and any required limits.
  4. Test the relationship and correct reversed or misplaced motion.

Quality check: The joint holds the parts in the intended relationship without unintended freedom or misalignment.
