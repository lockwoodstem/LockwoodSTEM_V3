Design & Print a Manufacturing Tolerance Tester

Focus question: How can engineers design a test coupon that produces useful evidence about fit and hardware interfaces?

Lesson Goal

Create and print a controlled test coupon for peg/hole clearance and heat-set insert hole sizing.

Expected result: Complete the required work and verify the CAD or manufacturing evidence before submitting.

Lesson Overview

What You Are Learning

Learning Targets

  • Create a controlled peg/hole clearance series.
  • Create a range of heat-set insert test holes.
  • Use parameters, patterns, labels, and standardized manufacturing settings.

Assignment

Design & Print a Manufacturing Tolerance Tester

You will design a controlled test coupon that measures two manufacturing relationships: peg/hole fit and heat-set insert hole sizing. The goal is to create data that can be used in future CAD designs.

Step-by-Step Instructions

  1. Create the tester base: Design a compact base large enough to contain both test series while minimizing unnecessary material.
  2. Build the peg/hole test series: Create the assigned peg and hole geometry using parameters or controlled dimensions. Label each test position clearly so the printed result can be identified after manufacturing.
  3. Build the heat-set insert series: Create the assigned range of candidate hole sizes for the standardized classroom insert. Use the actual dimensions/range provided by the instructor; do not invent your own test sizes.
  4. Use efficient CAD features: Use parameters and pattern tools where appropriate so test values can be changed without redrawing the entire coupon.
  5. Verify every test size: Use Inspect/Measure before export. A mislabeled or incorrectly dimensioned feature will make the experiment unusable.
  6. Record predictions: Before printing, predict which peg/hole condition will produce the best press/snug fit, which will produce the best slip fit, and which heat-set insert hole will work best.
  7. Prepare and slice the print: Export the tester and slice it using the standardized class printer, material, nozzle, layer height, and other assigned settings. Do not change the controlled manufacturing settings unless instructed.
  8. Print and preserve the tester: Print the coupon and keep it intact for the physical testing in Lesson 2.16.

Before You Submit

  • Each test location is clearly labeled.
  • Peg/hole values are dimensionally correct.
  • Insert-hole values match the instructor-provided test range.
  • Manufacturing settings match the class standard.
  • Predictions are recorded before physical testing.
Submission

What You Will Submit

  • Fusion archive: tolerance tester exported as LastName_FirstName_2_15_ToleranceTester.f3d.
  • Bambu Studio project: final sliced tester saved as LastName_FirstName_2_15_ToleranceTester.3mf.
  • Preview screenshot: Bambu Studio Preview with print-time/material estimate visible. Save as LastName_FirstName_2_15_Preview.png.
  • Predictions: record the predicted best press/snug fit, predicted best slip fit, and predicted best heat-set insert hole size.
  • Physical tester: keep the printed part for Lesson 2.16. Do not dispose of or modify it before testing.

File requirements: Export the editable CAD model using File → Export → Fusion 360 Archive Files (*.f3d). In Bambu Studio, choose File → Save Project As to save the final sliced setup as .3mf.
