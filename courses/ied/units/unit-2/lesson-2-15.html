IED Unit 2 · Lesson 2.15

Design & Print a Manufacturing Tolerance Tester

Essential question: How can engineers design a test coupon that produces useful evidence about fit and hardware interfaces?

Lesson goalCreate and print a controlled test coupon for peg/hole clearance and heat-set insert hole sizing.
Deliverable2.15 Additive Manufacturing Tolerance Tester
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

User ParametersHole/CutPatternText/LabelsInspect/MeasureMesh Export

Instructor Demonstration

  1. Set up useful user parameters for nominal size and clearance values.
  2. Create the compact tester base.
  3. Build a controlled peg/hole clearance series.
  4. Create and label the heat-set insert test-hole series.
  5. Verify dimensions, export, and slice using the standardized class settings.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Create one controlled fit pair and one labeled heat-set insert test hole with the instructor.

Assignment

  1. Complete the full tolerance tester with the required clearance range and heat-set insert hole range.
  2. Make predictions before printing, then manufacture the tester using standardized settings.

Before You Submit

  • Tester includes peg/hole fit tests.
  • Tester includes heat-set insert hole tests.
  • Every test size is clearly identified.
  • Critical dimensions are verified.
  • Print settings match the class standard.
