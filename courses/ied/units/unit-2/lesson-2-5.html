Assignment

Creating 3D Parts with Extrude — Bracket 3

You will begin modeling Bracket 3 using the technical drawing you created in Unit 1. This is the first part of one continuous model that will continue through Lessons 2.6 and 2.7.

Step-by-Step Instructions

  1. Open the correct source information: Have your Bracket 3 technical documentation visible before modeling. Identify the best base face and the overall thickness of the part.
  2. Create the base sketch: Choose the origin plane that most directly matches the primary view of Bracket 3. Sketch the outside profile of the base geometry and fully constrain it using the dimensions from the drawing.
  3. Check the sketch before extruding: Confirm that the profile is closed and that every critical base dimension matches the technical drawing.
  4. Create the first solid feature: Use Extrude to give the base sketch the specified thickness. Make sure the operation creates a new solid body and that the direction and distance are correct.
  5. Verify the model: Use Inspect/Measure to check the overall width, height, and thickness. If a dimension is wrong, edit the original sketch or Extrude feature instead of adding corrective geometry.
  6. Keep the Timeline organized: Rename the base sketch or Extrude feature if directed by the instructor. Do not create holes, cuts, fillets, or chamfers yet.

Before You Submit

  • Base sketch matches the Unit 1 drawing.
  • Extrude thickness is correct.
  • Overall dimensions verify correctly.
  • Only the base solid exists at the end of the lesson.
Submission

What You Will Submit

  • Fusion archive snapshot: current Bracket 3 model exported as LastName_FirstName_2_5_Bracket3.f3d.
  • Isometric screenshot: base model with Browser and Timeline visible. Save as LastName_FirstName_2_5_Bracket3.png.

File requirements: Continue working in the same Bracket 3 cloud design through Lessons 2.5–2.7. For this lesson submission, create a snapshot with File → Export → Fusion 360 Archive Files (*.f3d). Do not create a separate cloud design just for submission.
