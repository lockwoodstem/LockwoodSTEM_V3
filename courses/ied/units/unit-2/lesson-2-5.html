Your Task

Begin recreating Bracket 3 by modeling only the base solid geometry.

  1. Review the existing Bracket 3 engineering documentation.
  2. Choose the best starting plane and sketch strategy.
  3. Create and fully constrain the base sketch.
  4. Extrude the profile to the specified thickness and verify overall dimensions.

Quality check: Bracket 3 has the correct base geometry and is ready for functional features.

What You Will Submit

Required Evidence

  • Bracket 3 Fusion file with base sketch and base extrusion.
  • Isometric screenshot with Browser and Timeline visible.
  • Verification of overall width, height, and thickness.

Submission standard: Evidence must clearly show the finished work and the verification required by this lesson.
