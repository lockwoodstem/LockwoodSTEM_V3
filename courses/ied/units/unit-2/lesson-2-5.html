IED Unit 2 · Lesson 2.5

Creating 3D Parts with Extrude — Bracket 3

Essential question: How can a 2D sketch be transformed into an accurate 3D part?

Lesson goalUse the existing Bracket 3 documentation from Lesson 1.5 to create the base solid in Fusion.
DeliverableBracket 3 Base Model
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

ExtrudeDistanceOne SideSymmetricJoinNew BodyInspect/Measure

Instructor Demonstration

  1. Review Bracket 3 and identify the best base profile before opening Fusion.
  2. Create the base sketch on the most useful plane.
  3. Demonstrate Extrude distance and direction options.
  4. Edit the source sketch and extrusion from the Timeline to show parametric behavior.
  5. Verify the base part dimensions using Inspect/Measure.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Follow the instructor through the initial setup and first base feature only.

Assignment

  1. Complete the Bracket 3 base geometry from the Lesson 1.5 documentation.
  2. Do not add holes, cuts, fillets, or chamfers yet.

Before You Submit

  • Base sketch is fully constrained.
  • Base solid dimensions are correct.
  • Timeline contains a logical Sketch → Extrude sequence.
  • Critical dimensions have been verified with Inspect/Measure.
