IED Unit 2 · Lesson 2.1

Getting Started with Fusion

Essential question: How do engineers organize and navigate a CAD workspace before creating a model?

Lesson goalLearn the Fusion interface, organize files correctly, and move confidently around a 3D model.
DeliverableFusion Setup & Navigation Check
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

Data PanelBrowserTimelineViewCubeOrbitPanZoom

Instructor Demonstration

  1. Create a new design and save it in the correct course/project location.
  2. Point out the Data Panel, Browser, Origin, Toolbar, ViewCube, Canvas, and Timeline.
  3. Demonstrate orbit, pan, zoom, standard views, Home View, and returning to an isometric view.
  4. Close the file, navigate away from it, locate it again, and reopen it.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Use the teacher-provided model to reproduce Front, Top, Right, Isometric, Bottom, and one custom rotated view.
  2. Practice orbit, pan, and zoom without changing the model geometry.
  3. Return to Home View and verify the Browser and Timeline are visible.

Assignment

  1. Create a correctly named Fusion file using the class naming convention.
  2. Capture one screenshot showing the correct file name and workspace.
  3. Capture one screenshot of the teacher-provided model in the assigned orientation.
  4. Answer: Where would you look to see the sequence of features used to create a model?

Before You Submit

  • File name is correct.
  • File is saved in the correct location.
  • Browser and Timeline are visible.
  • Assigned model orientation is correct.
  • File can be closed and reopened successfully.

What You Submit

Fusion Setup & Navigation Check

Submit the file(s), screenshots, measurements, or written evidence specified by your instructor for this lesson.
