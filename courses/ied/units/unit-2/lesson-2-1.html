Opening Prompt

How do engineers organize and navigate a CAD workspace before creating a model?

Use what you already know from engineering documentation, CAD, or manufacturing to make an initial prediction before the demonstration begins.

Reveal: engineering habit for this lesson

Plan the feature or manufacturing decision before clicking commands. Then verify the result instead of assuming the model is correct because it looks right.

Your Task

Complete the Fusion Setup & Navigation Check using a teacher-provided model.

  1. Create and correctly name a new Fusion design.
  2. Identify the Browser, Timeline, Origin, Sketch tools, Solid workspace, Data Panel, and ViewCube.
  3. Reproduce the requested model views using orbit, pan, zoom, and standard views.
  4. Save, close, locate, and reopen the file.

Quality check: Your Fusion workspace is organized and ready for modeling.

What You Will Submit

Required Evidence

  • Screenshot of the correctly named Fusion file.
  • Screenshot identifying major interface regions.
  • Screenshot of the teacher-provided model in the required orientation.
  • Short response identifying where Fusion shows feature history.

Submission standard: Evidence must clearly show the finished work and the verification required by this lesson.
