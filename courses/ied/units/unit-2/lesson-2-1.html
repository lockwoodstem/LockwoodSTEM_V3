Assignment

Getting Started with Fusion

This lesson is about learning how to work efficiently inside Fusion before you begin modeling. Do not create a part yet. Your goal is to become comfortable finding files, changing views, and locating the major interface areas you will use throughout Unit 2.

Step-by-Step Instructions

  1. Create and name your design: Open Fusion and create a new design. Rename it using the class naming convention before doing anything else. Make sure the correct project/folder is selected in the Data Panel so you will be able to find the file again later.
  2. Identify the major interface areas: Locate the Data Panel, Browser, Origin folder, main Toolbar, ViewCube, Canvas, and Timeline. Be prepared to explain what each area is used for. Expand and collapse the Browser so you understand where sketches, bodies, components, and origin planes will appear.
  3. Practice camera controls: Use orbit, pan, and zoom until you can intentionally move to front, top, right, and isometric views. Use the ViewCube and Home command to return to a known orientation. Do not rely only on the mouse wheel; practice each navigation method shown by the instructor.
  4. Work with the provided model: Open the teacher-provided practice model and reproduce the assigned views. Move between standard and isometric orientations without changing the model geometry.
  5. Practice file management: Save the design, close it, locate it again in the Data Panel, and reopen it. Confirm that the filename and project location are correct before the end of class.

Before You Submit

  • You can find the file again after closing it.
  • You can return to a standard view without guessing.
  • You can identify the Browser and Timeline and explain the difference between them.
