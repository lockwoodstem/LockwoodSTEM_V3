IED Unit 2 · Lesson 2.6

Cut Features and Holes — Bracket 3

Essential question: How can engineers precisely remove material from a CAD model to create functional features?

Lesson goalContinue Bracket 3 by adding openings, cut features, and engineered holes.
DeliverableBracket 3 Functional Features
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

Sketch on FaceExtrude CutThrough AllHole

Instructor Demonstration

  1. Create a sketch on an existing planar face.
  2. Use Extrude with the Cut operation for non-circular removed geometry.
  3. Compare Distance and Through All cut extents.
  4. Use the dedicated Hole tool and explain when it is preferable to a sketched circle plus Cut.
  5. Edit a cut or hole feature from the Timeline.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Add one required feature to Bracket 3 with the instructor, then verify its size and location.

Assignment

  1. Complete all required cut and hole features shown in the Bracket 3 documentation.

Before You Submit

  • All openings match the source documentation.
  • Hole diameter and location are correct.
  • Cut extent represents the intended geometry.
  • No fillets or chamfers have been added yet.
