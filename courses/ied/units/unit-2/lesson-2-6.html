Cut Features and Holes — Bracket 3

Focus question: How can engineers precisely remove material from a CAD model to create functional features?

Go to AssignmentVideo HelpBack to Unit 2
Lesson Goal

Continue Bracket 3 by creating openings, cut features, and engineered holes.

Expected result: Complete the required work and verify the CAD or manufacturing evidence before submitting.

Lesson Overview

What You Are Learning

Learning Targets

  • Create sketches on existing planar faces.
  • Use Extrude Cut for custom removed geometry.
  • Use the Hole tool for engineered circular holes.

Assignment

Cut Features and Holes — Bracket 3

Continue the same Bracket 3 file from Lesson 2.5. This lesson focuses on removing material accurately using Extrude Cut and the Hole tool.

Step-by-Step Instructions

  1. Open the existing Bracket 3 design: Do not start a new model. Use the same cloud design so the Timeline shows the progression from the original base feature.
  2. Plan each removed feature: Use the technical drawing to identify which features are custom cutouts and which are true circular holes.
  3. Create custom cut geometry: Sketch the required non-circular openings on the correct face. Fully constrain their position and size, then use Extrude with the Cut operation.
  4. Create engineered holes: Use the Hole tool for circular holes where appropriate. Set the location, diameter, and extent from the drawing rather than approximating the hole with an arbitrary sketch circle.
  5. Check cut extent: Verify whether each cut is Through All, To Object, or a specified depth. Make sure the result matches the documentation.
  6. Measure the finished features: Use Inspect/Measure to confirm hole diameters, center locations, spacing, and cut geometry.

Before You Submit

  • Custom openings use appropriate cut features.
  • Circular engineered holes use the Hole tool where directed.
  • Feature locations and diameters match the drawing.
  • The original base feature remains editable in the Timeline.
Submission

What You Will Submit

  • Fusion archive snapshot: updated Bracket 3 model exported as LastName_FirstName_2_6_Bracket3.f3d.
  • Isometric screenshot: completed cuts and holes with the Timeline visible. Save as LastName_FirstName_2_6_Bracket3.png.

File requirements: Continue editing the same Bracket 3 cloud design. Create the submission snapshot with File → Export → Fusion 360 Archive Files (*.f3d).
