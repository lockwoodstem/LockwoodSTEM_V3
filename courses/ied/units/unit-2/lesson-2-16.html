IED Unit 2 • Lesson 2.16

Tolerance Testing & Manufacturing Recommendations

Focus question: How can physical test results be used to improve future CAD designs?

Go to AssignmentVideo HelpBack to Unit 2
Lesson Goal

Use physical testing to establish evidence-based fit and heat-set insert design recommendations.

Expected result: Complete the required work and verify the CAD or manufacturing evidence before submitting.

Lesson Overview

What You Are Learning

Learning Targets

  • Inspect a printed tester before trusting the data.
  • Classify peg/hole fit behavior.
  • Evaluate heat-set insert installation and retention.
  • Convert results into documented CAD recommendations.

How to Approach the Work

Use the instructor demonstration to understand the tool or design decision, then complete the assigned work independently and verify the result before submission.

Assignment

Tolerance Testing & Manufacturing Recommendations

Use the printed tester from Lesson 2.15 to collect manufacturing evidence. Your final recommendations must be tied to the specific printer, material, nozzle, layer height, and other conditions used for this test.

Step-by-Step Instructions

  1. Inspect the coupon first: Check for warping, under-extrusion, damaged features, elephant foot, or other print problems that could invalidate individual measurements.
  2. Test the peg/hole series: Try each assigned pairing and classify the fit consistently. Record whether it behaves as interference/press, snug, slip, loose, or another class-defined category.
  3. Do not force failed fits: If a peg clearly will not assemble by normal hand pressure, record the result rather than damaging the coupon.
  4. Install the heat-set inserts safely: Use the demonstrated insertion procedure and appropriate PPE/tools. Test each candidate hole only as directed so the comparison remains meaningful.
  5. Evaluate insert behavior: Record installation effort, alignment, retention, surrounding plastic deformation, and whether the insert remains secure.
  6. Compare predictions with results: Identify which predictions from Lesson 2.15 were correct and where the physical result differed.
  7. Write manufacturing recommendations: State the recommended CAD clearance(s) and heat-set insert hole diameter for the tested configuration. Include the printer, material, nozzle size, layer height, and any other controlled settings.
  8. State the limitation: Make clear that your results apply to the tested manufacturing configuration and should not automatically be treated as universal values for every printer/material combination.

Before You Submit

  • Every tested condition has a recorded result.
  • Recommendations are based on physical evidence.
  • Manufacturing conditions are documented.
  • Results are presented as configuration-specific rather than universal constants.
Submission

What You Will Submit

  • Manufacturing recommendations document: submit one document or PDF named LastName_FirstName_2_16_ManufacturingRecommendations.
  • The document must include: observed fit for each tested clearance, heat-set insert results, prediction-versus-result comparison, recommended press/snug-fit clearance, recommended slip-fit clearance, recommended heat-set insert hole diameter, and the printer/material/nozzle/layer-height conditions used.
  • Tester photo: one clear image of the completed tester with the installed heat-set insert(s). Save as LastName_FirstName_2_16_Tester.jpg or PNG.

File requirements: If the report is created in another program, export the finished version as PDF before submitting. No Fusion file is required for this lesson unless specifically requested.
