Your Task

Create an Accurate Fin Pattern

Use symmetry or a circular pattern to repeat one fin at equal spacing around the rocket body.

  1. Model or identify one correctly positioned source fin.
  2. Select the rocket axis as the pattern axis.
  3. Set the required number of repeated fins.
  4. Inspect spacing and orientation from the top and isometric views.

Quality check: All fins are equally spaced, aligned, and generated from one controlled source feature.
