Assignment

Fillets, Chamfers, and Design Intent — Bracket 3

You will complete Bracket 3 by adding edge treatments and then perform a final model verification. The goal is not just to make the part look finished; each feature should exist for a reason.

Step-by-Step Instructions

  1. Compare the current model with the technical drawing: Identify every remaining fillet, chamfer, radius, or finishing feature that is still missing.
  2. Add fillets: Select only the edges that should receive the specified radius. Confirm the correct radius value before accepting the feature.
  3. Add chamfers: Apply the required chamfer type and distance/angle. Verify that the chamfer removes material from the intended edge.
  4. Review feature order: Look at the Timeline and confirm the feature order is logical. If a feature fails when an earlier dimension changes, investigate whether the model references are robust.
  5. Perform a complete dimensional check: Measure the overall part and at least the critical holes, cutouts, and edge features. Compare the final model directly with your Unit 1 documentation.
  6. Clean the file: Remove unused sketches or accidental geometry only if they are truly unnecessary. Leave the model organized so another person can understand how it was built.

Before You Submit

  • All required edge treatments are present.
  • Final dimensions match the technical drawing.
  • Timeline is readable and does not contain obvious accidental features.
  • Bracket 3 is complete at the end of this lesson.
Submission

What You Will Submit

  • Final Fusion archive: completed Bracket 3 exported as LastName_FirstName_2_7_Bracket3_Final.f3d.
  • Final model screenshot: isometric view with Browser and Timeline visible. Save as LastName_FirstName_2_7_Bracket3_Final.png.
  • Written response: identify one fillet or chamfer and explain its design purpose.

File requirements: Export the final editable model using File → Export → Fusion 360 Archive Files (*.f3d). Submit the archive and PNG evidence.
