Sketch Planes and 2D Sketching

Focus question: How does a 2D sketch become the foundation of a CAD model?

Mission Focus

Mission Briefing

45-Minute Flight Plan

Use this page with the lesson presentation, Fusion 360, and your engineering notebook.

Learning Targets

  • Choose a sketch plane intentionally.
  • Create a readable 2D base sketch.
  • Explain how sketch orientation affects the final model.

Success Looks Like

Your sketch begins on a plane that matches the part’s intended shape and view.

LaunchLearnModelCheckSubmit
Opening Prompt

What could go wrong if you start sketching on the wrong plane?

Think first, then share a response that connects today’s CAD skill to accuracy, editability, printability, or evidence quality.

Reveal: useful CAD thinking move

The model can become hard to orient, edit, document, or assemble because the geometry begins from a confusing reference.

Core Skill

What We Are Practicing

Key Idea 1

The sketch plane controls where geometry begins.

Key Idea 2

2D sketches define the base shape of most 3D parts.

Key Idea 3

Poor sketch placement creates confusing models.

Interactive Check

What is the best first decision before sketching?

APick any plane quickly
BChoose the plane that matches the intended main view
CAdd small details before the base shape
DExtrude before the sketch is closed
Reveal Answer

B — Choose the plane that matches the intended main view

A planned sketch plane makes the model easier to build, edit, and explain.

Engineering Workflow

Use These Moves

  1. Choose a plane that matches the intended view.
  2. Start with simple geometry before details.
  3. Keep sketches readable and organized.
Student Task

Apply the Skill

Create a simple base sketch on an intentional plane and explain why that plane makes sense for the part.

Checkpoint: be ready to show the CAD evidence that proves your work is controlled, accurate, printable, or ready to revise.

Evidence Challenge

What evidence would you need?

Claim: “My sketch planes and 2d sketching work is accurate and ready to move forward.”

AA screenshot or model view that shows the feature
BA statement that it looks good
CRelevant dimensions, settings, or test results
DA random file name
Reveal Answer

A + C are the strongest evidence pair. They show what was created and whether it meets the requirement.

Scenario Response

What should the engineer do next?

A student wants the front face of a part to become the main profile. Which modeling move is strongest?

ASketch on a plane that represents the front view
BSketch on the top plane every time
CCreate the smallest detail first
DUse 3D features without a sketch
Reveal Answer

A — Sketch on a plane that represents the front view

The strongest next step records the issue, identifies the likely cause, and turns the result into useful CAD evidence.

Student Deliverables

What You Submit
