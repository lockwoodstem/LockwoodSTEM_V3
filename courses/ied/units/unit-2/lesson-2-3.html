Sketch Constraints

Focus question: How can constraints make a CAD sketch behave the way an engineer intends?

Lesson Goal

Control geometric relationships so sketches behave predictably when edited.

Expected result: Complete the required work and verify the CAD or manufacturing evidence before submitting.

Lesson Overview

What You Are Learning

Learning Targets

  • Apply common geometric constraints.
  • Diagnose under-constrained geometry by dragging.

Assignment

Sketch Constraints

Constraints control how sketch geometry is allowed to move. Your job is to repair sketches using geometric relationships rather than locking geometry in place with Fix/UnFix.

Step-by-Step Instructions

  1. Test each broken sketch first: Before adding any constraint, click and drag geometry to see how the sketch currently moves. Use the motion to identify what relationship is missing.
  2. Apply geometric constraints: Use Horizontal/Vertical, Coincident, Parallel, Perpendicular, Tangent, Equal, Concentric, Midpoint, and Symmetry as appropriate. Use the smallest number of constraints needed to communicate the design intent.
  3. Re-test the sketch: Drag the geometry again after each repair. A correct constraint should stop the unwanted motion while still allowing any intended freedom.
  4. Avoid unnecessary Fix/UnFix: Do not use Fix/UnFix as a shortcut to make geometry turn black. A sketch is only well constrained when its relationships and dimensions control it for a reason.
  5. Revise the Lesson 2.2 mounting plate: Open your mounting-plate sketch and add the appropriate geometric relationships. Leave dimensions for Lesson 2.4, so some controlled dimensional freedom should remain.
  6. Identify remaining degrees of freedom: Determine what can still move or change in the mounting plate and be ready to explain what dimension would eventually control it.

Before You Submit

  • Constraints match the intended geometry.
  • The sketch does not rely on Fix/UnFix as the primary control method.
  • The mounting plate still has intentional dimensional freedom.
Submission

What You Will Submit

  • Fusion archive: one design containing the five repaired sketches and revised mounting plate. Export as LastName_FirstName_2_3_Constraints.f3d.
  • Written response: identify one remaining degree of freedom in the mounting plate and explain what information would be needed to remove it.

File requirements: Export the editable design using File → Export → Fusion 360 Archive Files (*.f3d). Submit the exported .f3d file rather than a link to your Fusion project.
