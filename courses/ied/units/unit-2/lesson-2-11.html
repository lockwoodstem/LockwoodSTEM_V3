Your Task

Make a Rocket Part Parametric

Identify important design values and make at least one of them easy to revise without rebuilding the model.

  1. Select a dimension that controls a meaningful feature.
  2. Give the value a clear parameter or dimension role.
  3. Change the value to test how the model updates.
  4. Restore or set the final required value and inspect downstream features.

Quality check: The selected value changes the intended geometry without breaking unrelated features.

What You Will Submit

Parametric Revision Test

  • The saved model with at least one clearly identifiable editable design value.
  • Before-and-after screenshots or a short note documenting the revision test.

Submission standard: The selected value changes the intended geometry without breaking unrelated features.
