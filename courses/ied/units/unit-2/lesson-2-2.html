Why does file setup matter before a model even exists?

Reveal: useful CAD thinking move

A model that is saved in the correct location, named clearly, and set to the correct units is easier to find, revise, submit, and inspect.

Core Skill

What We Are Practicing

Key Idea 1

The interface is a tool system: browser, timeline, sketch tools, view cube, and units.

Key Idea 2

File setup affects every model made afterward.

Key Idea 3

A clean project folder prevents lost or duplicated work.

Your Task

Set Up a Professional Fusion Workspace

Prepare the correct Fusion project, file, units, and workspace so later modeling work is organized from the beginning.

  1. Open or create the assigned project location.
  2. Create a new design with the required file name.
  3. Confirm the document units before drawing geometry.
  4. Locate the browser, timeline, view cube, and sketch tools.

Quality check: Another student could open the project and immediately identify the correct file and units.
