IED Unit 2 · Lesson 2.2

Sketch Planes and 2D Sketching

Essential question: How does the plane an engineer chooses affect the way a CAD model is created?

Lesson goalCreate clean 2D sketch geometry on an intentional origin plane.
Deliverable2.2 Sketching Skills Check
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

Create SketchXY/XZ/YZ PlanesLineRectangleCircleArcTrim

Instructor Demonstration

  1. Show the three origin planes and connect them to front/top/side views from Unit 1.
  2. Create a sketch on a selected plane and deliberately use the sketch origin.
  3. Demonstrate Line, Rectangle, Circle, Arc, and Trim on a simple profile.
  4. Finish the sketch and reopen it for editing.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Create a rectangle with a circular opening.
  2. Create an L-shaped profile.
  3. Create a profile containing an arc.
  4. Create a profile that requires Trim.

Assignment

  1. Create the independent mounting-plate profile shown by the instructor.
  2. Use only the tools introduced in this lesson.
  3. Do not add dimensions or formal geometric constraints yet.

Before You Submit

  • Correct sketch plane selected.
  • Geometry is connected and readable.
  • Required tools are used correctly.
  • Independent mounting-plate profile is complete.

What You Submit

Submit the file(s), screenshots, measurements, or written evidence specified by your instructor for this lesson.
