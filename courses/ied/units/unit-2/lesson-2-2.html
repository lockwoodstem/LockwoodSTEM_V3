Fusion 360 Interface and File Setup

Focus question: How do engineers set up a CAD file for organized work?

Download PresentationFlight PlanWhat You SubmitBack to Unit 2
Mission Focus

Your CAD workspace is organized before geometry is created.

SetupOrganizeSave

Use CAD choices as evidence, not just screen work.

Mission Briefing

45-Minute Flight Plan

Use this page with the lesson presentation, Fusion 360, and your engineering notebook.

Learning Targets

  • Locate the major Fusion 360 workspace areas.
  • Create or open the correct project and file location.
  • Use professional naming and units before modeling.

Success Looks Like

Your CAD workspace is organized before geometry is created.

LaunchLearnModelCheckSubmit
Opening Prompt

Why does file setup matter before a model even exists?

Think first, then share a response that connects today’s CAD skill to accuracy, editability, printability, or evidence quality.

Reveal: useful CAD thinking move

A model that is saved in the correct location, named clearly, and set to the correct units is easier to find, revise, submit, and inspect.

Core Skill

What We Are Practicing

Key Idea 1

The interface is a tool system: browser, timeline, sketch tools, view cube, and units.

Key Idea 2

File setup affects every model made afterward.

Key Idea 3

A clean project folder prevents lost or duplicated work.

Interactive Check

Which setup habit prevents the most problems later?

AStarting with random units
BSaving only at the end of class
CUsing a clear file name and correct project folder
DKeeping every file on the desktop
Reveal Answer

C — Using a clear file name and correct project folder

Clear location and naming make the file findable and reduce version-control problems.

Engineering Workflow

Use These Moves

  1. Create or open the correct project location.
  2. Set units before modeling.
  3. Save early with a professional file name.
Student Task

Apply the Skill

Open Fusion 360, confirm your project location, set units, and save a test file using the required naming format.

Checkpoint: be ready to show the CAD evidence that proves your work is controlled, accurate, printable, or ready to revise.

Evidence Challenge

What evidence would you need?

Claim: “My fusion 360 interface and file setup work is accurate and ready to move forward.”

AA screenshot or model view that shows the feature
BA statement that it looks good
CRelevant dimensions, settings, or test results
DA random file name
Reveal Answer

A + C are the strongest evidence pair. They show what was created and whether it meets the requirement.

Scenario Response

What should the engineer do next?

A student creates a model in the wrong project folder and cannot find it the next day. What should they change going forward?

ANever save until the model is perfect
BCreate/open the correct project first and save immediately
CUse shorter file names with no details
DOnly submit screenshots
Reveal Answer

B — Create/open the correct project first and save immediately

The strongest next step records the issue, identifies the likely cause, and turns the result into useful CAD evidence.
