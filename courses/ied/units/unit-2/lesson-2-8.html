IED Unit 2 • Lesson 2.8

Fillets, Chamfers, and Design Intent

Focus question: How do edge features improve function, safety, and printability?

Mission Focus

Your edge features have a reason beyond appearance.

Mission Briefing

45-Minute Flight Plan

Use this page with the lesson presentation, Fusion 360, and your engineering notebook.

Learning Targets

  • Distinguish between fillets and chamfers.
  • Apply edge features intentionally.
  • Explain how edge treatment affects function or manufacturing.

Success Looks Like

Your edge features have a reason beyond appearance.

LaunchLearnModelCheckSubmit
Opening Prompt

When might rounding an edge make a part worse instead of better?

Think first, then share a response that connects today’s CAD skill to accuracy, editability, printability, or evidence quality.

Reveal: useful CAD thinking move

If the edge controls fit, alignment, or contact with another part, changing it without a reason can reduce accuracy or function.

Core Skill

What We Are Practicing

Key Idea 1

Fillets and chamfers can improve safety, strength, fit, and printability.

Key Idea 2

Edge treatment should support the function, not just appearance.

Key Idea 3

Design intent explains why a feature exists.

Interactive Check

Which explanation shows design intent?

AI added fillets because they look nice
BI filleted the hand-contact edge to reduce sharpness
CI changed every edge randomly
DI added chamfers because the menu was available
Reveal Answer

B — I filleted the hand-contact edge to reduce sharpness

It connects the feature to a function: safer handling.

Engineering Workflow

Use These Moves

  1. Identify edges that need treatment.
  2. Apply fillets or chamfers with reasonable sizes.
  3. Avoid changing critical fit surfaces without a reason.
Student Task

Apply the Skill

Add intentional edge features to a model and label the design reason for each.

Checkpoint: be ready to show the CAD evidence that proves your work is controlled, accurate, printable, or ready to revise.

Evidence Challenge

What evidence would you need?

Claim: “My fillets, chamfers, and design intent work is accurate and ready to move forward.”

AA screenshot or model view that shows the feature
BA statement that it looks good
CRelevant dimensions, settings, or test results
DA random file name
Reveal Answer

A + C are the strongest evidence pair. They show what was created and whether it meets the requirement.

Scenario Response

What should the engineer do next?

A student fillets a peg that must fit tightly into a hole. What should they consider?

AWhether the fillet changes the fit surface
BWhether the part looks more advanced
CWhether the timeline is longer
DWhether the file saves faster
Reveal Answer

A — Whether the fillet changes the fit surface

The strongest next step records the issue, identifies the likely cause, and turns the result into useful CAD evidence.

Student Deliverables

What You Submit

  • Part includes intentional edge treatment.
  • Student explains why each treatment was added.
  • Critical dimensions are still protected.
  • Exit response connecting the skill to CAD evidence or model quality
