Creating Rotational Parts with Revolve

Focus question: How can engineers create rotationally symmetric 3D parts from a 2D profile?

Assignment

Creating Rotational Parts with Revolve

Revolve is used when a part is primarily defined by a profile rotated around an axis. You will build a rotational component from a dimensioned half-profile.

Step-by-Step Instructions

  1. Interpret the drawing: Identify the center axis and determine which half of the part should be represented in the sketch.
  2. Create the half-profile: Sketch only one side of the cross-section. Use a construction centerline for the axis of rotation.
  3. Constrain and dimension the profile: Apply the required geometric relationships and dimensions until the profile is fully defined.
  4. Create the Revolve feature: Select the profile, choose the construction centerline as the axis, and revolve the profile 360 degrees.
  5. Test parametric behavior: Edit one assigned source dimension and confirm that the 3D model updates correctly. Then return the value to the specified final dimension.
  6. Verify the solid: Use Inspect/Measure to confirm the major diameters, lengths, and any stepped geometry.

Before You Submit

  • Only a half-profile was needed to create the full part.
  • The revolve axis is a construction line.
  • The model updates when a source dimension changes.
  • Final values match the assigned drawing.
Submission

What You Will Submit

  • Fusion archive: completed rotational component exported as LastName_FirstName_2_8_Revolve.f3d.
  • Profile screenshot: fully constrained half-profile with dimensions visible. Save as LastName_FirstName_2_8_Profile.png.
  • Final model screenshot: completed revolved solid in isometric view. Save as LastName_FirstName_2_8_Final.png.

File requirements: Export the editable design using File → Export → Fusion 360 Archive Files (*.f3d). Save both evidence images as PNG.
