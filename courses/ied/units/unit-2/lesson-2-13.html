Student Task

Prepare a CAD Body for Export

Select the correct body, verify scale and orientation, and create a clearly named print-ready mesh file.

  1. Confirm the intended body is separate and complete.
  2. Check model units and overall size.
  3. Choose an orientation that provides a reasonable starting point for slicing.
  4. Export the body with the required file name and format.

Quality check: The exported file represents only the intended body at the correct scale.
