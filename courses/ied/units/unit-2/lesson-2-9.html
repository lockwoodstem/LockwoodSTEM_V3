IED Unit 2 • Lesson 2.9

Mirror and Pattern Tools

Focus question: How can symmetry and repetition be used to create CAD models more efficiently?

Assignment & SubmissionVideo HelpBack to Unit 2
Lesson Goal

Use Mirror and Pattern features to create repeated geometry efficiently and maintain design intent.

Expected result: Complete the required work and verify the CAD or manufacturing evidence before submitting.

Lesson Overview

What You Are Learning

Learning Targets

  • Use Mirror to reproduce symmetric features.
  • Use Rectangular Pattern to repeat a source feature.
  • Edit a source feature and observe dependent geometry update.

How to Approach the Work

Use the instructor demonstration to understand the tool or design decision, then complete the assigned work independently and verify the result before submission.

LearnModelVerifyReviseSubmit
Google Classroom Assignment

Assignment & Submission

Complete the Work

  1. Model the equipment mounting plate with symmetric mounting holes and a repeated ventilation pattern.
  2. Create repeated geometry with Mirror and Pattern features instead of manually duplicating features.
  3. Complete the engineering change request by editing the original source features and confirming the dependent features update correctly.

Submit to Google Classroom

  • Fusion archive: export the completed mounting plate as LastName_FirstName_2_9_PatternPlate.f3d.
  • Screenshot 1: final isometric model with Timeline visible. Save as LastName_FirstName_2_9_Final.png.
  • Screenshot 2: evidence of the completed engineering change request after the source feature was edited. Save as LastName_FirstName_2_9_ECR.png.
  • Private comment: state which original feature you edited and which dependent features updated automatically.

File submission instructions: Export the Fusion archive with File → Export → Fusion 360 Archive Files (*.f3d). Save both screenshots as PNG. Attach all three files in Google Classroom and add the short ECR explanation in the private comment.
