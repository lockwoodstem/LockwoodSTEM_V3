IED Unit 2 · Lesson 2.9

Mirror and Pattern Tools

Essential question: How can symmetry and repetition be used to create CAD models more efficiently?

Lesson goalUse feature reuse to model a patterned equipment mounting plate efficiently.
Deliverable2.9 Patterned Equipment Mounting Plate
Instructor DemonstrationAssignmentVideo Help

New Skills and Tools

MirrorRectangular PatternFeature SelectionPattern QuantityPattern Spacing

Instructor Demonstration

  1. Create one mounting hole and mirror the feature rather than rebuilding it.
  2. Create one ventilation feature and repeat it with Rectangular Pattern.
  3. Edit the source feature and show dependent geometry updating.
  4. Briefly show Circular Pattern as an additional option without requiring it.
During the demonstration: Follow along in Fusion only when directed. The goal is to understand the modeling decision, not simply copy clicks.

Practice

  1. Mirror one hole across a reference plane.
  2. Create a small rectangular pattern and change its quantity.

Assignment

  1. Complete the mounting plate with symmetric mounting holes and the required ventilation pattern.
  2. Complete the engineering change request by changing pattern quantity and mounting-hole diameter through the original features.

Before You Submit

  • Repeated geometry is not manually duplicated.
  • Mirror references are correct.
  • Pattern quantity and spacing match the drawing.
  • Engineering change request updates dependent features correctly.
