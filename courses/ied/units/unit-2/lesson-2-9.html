Opening Prompt

How can symmetry and repetition be used to create CAD models more efficiently?

Use what you already know from engineering documentation, CAD, or manufacturing to make an initial prediction before the demonstration begins.

Reveal: engineering habit for this lesson

Plan the feature or manufacturing decision before clicking commands. Then verify the result instead of assuming the model is correct because it looks right.

Your Task

Model a patterned equipment mounting plate with mirrored mounting holes and a repeated ventilation pattern.

  1. Create the base plate.
  2. Create one mounting hole and mirror it across the required references.
  3. Create one ventilation feature and build the rectangular pattern.
  4. Complete the engineering change request by changing pattern quantity and hole diameter.

Quality check: Repeated geometry is controlled by Mirror and Pattern rather than rebuilt one feature at a time.

What You Will Submit

Required Evidence

  • Patterned Equipment Mounting Plate Fusion file.
  • Isometric screenshot with Timeline visible.
  • Verification table for plate and pattern dimensions.
  • Evidence that the engineering change request was completed by editing source features.

Submission standard: Evidence must clearly show the finished work and the verification required by this lesson.
