Assignment

Mirror and Pattern Tools

You will build an equipment mounting plate while learning to reuse geometry efficiently. Repeated features should be controlled from a source feature rather than manually recreated.

Step-by-Step Instructions

  1. Create the base plate: Sketch and extrude the plate using the assigned dimensions.
  2. Create one mounting hole: Position and create a single source mounting hole accurately.
  3. Mirror symmetric geometry: Use Mirror to reproduce the mounting hole across the appropriate centerline/plane rather than drawing a second independent hole.
  4. Create one ventilation opening: Model a single opening that will become the source for the repeated ventilation pattern.
  5. Build the rectangular pattern: Use Rectangular Pattern to control the number of instances and spacing. Make sure the pattern remains inside the usable plate area.
  6. Complete the engineering change request: Edit the source ventilation feature quantity/spacing and the mounting-hole diameter as directed. Confirm that the mirrored and patterned features update automatically.
  7. Inspect the Timeline: Verify that the repeated geometry is represented by Mirror/Pattern features instead of a long sequence of individually modeled duplicates.

Before You Submit

  • Repeated geometry comes from source features.
  • The ECR can be completed by editing source features.
  • Pattern quantity and spacing are intentional.
  • No manually duplicated holes are used to imitate a pattern.
Submission

What You Will Submit

  • Fusion archive: completed equipment mounting plate exported as LastName_FirstName_2_9_PatternPlate.f3d.
  • Final model screenshot: isometric view with Timeline visible. Save as LastName_FirstName_2_9_Final.png.
  • ECR evidence screenshot: model after editing the source feature and allowing dependent patterned/mirrored features to update. Save as LastName_FirstName_2_9_ECR.png.
  • Written response: state which source feature you edited and which dependent features updated automatically.

File requirements: Export the Fusion model using File → Export → Fusion 360 Archive Files (*.f3d). Save both evidence images as PNG.
