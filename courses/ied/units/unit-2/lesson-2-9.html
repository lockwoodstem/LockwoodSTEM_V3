Revolve Features: Nose Cone and Nozzle

Focus question: How can rotation create aerospace-shaped parts?

Learning Targets

  • Sketch a profile for a revolved feature.

  • Connect revolve features to aerospace parts.

Success Looks Like

Your revolved model is built from a clear profile and axis.

Opening Prompt

Why is a nose cone a good example of a revolve feature?

Think first, then share a response that connects today’s CAD skill to accuracy, editability, printability, or evidence quality.

Reveal: useful CAD thinking move

A nose cone is rotationally symmetric. A 2D side profile can rotate around a centerline to form the full 3D part.

Core Skill

What We Are Practicing

Key Idea 1

Revolve creates circular parts from a profile and axis.

Key Idea 2

Profiles must be planned around the centerline.

Key Idea 3

Nose cones and nozzles are natural revolve examples.

Interactive Check

What does a revolve feature need?

AA profile and an axis
BA PDF and a table
CA slicer and a printer
DA photo and a caption
Reveal Answer

A — A profile and an axis

Revolve uses a 2D profile and rotates it around an axis to create a solid.

Engineering Workflow

Use These Moves

  1. Sketch half of the profile.
  2. Add a centerline or axis.
  3. Use revolve angle to create the 3D body.
Student Task

Apply the Skill

Create or analyze a revolved nose cone or nozzle profile and explain the axis of rotation.

Checkpoint: be ready to show the CAD evidence that proves your work is controlled, accurate, printable, or ready to revise.

Evidence Challenge

What evidence would you need?

Claim: “My revolve features: nose cone and nozzle work is accurate and ready to move forward.”

AA screenshot or model view that shows the feature
BA statement that it looks good
CRelevant dimensions, settings, or test results
DA random file name
Reveal Answer

A + C are the strongest evidence pair. They show what was created and whether it meets the requirement.

Scenario Response

What should the engineer do next?

A revolved part creates a strange self-intersecting shape. What should be checked first?

AWhether the profile crosses the centerline incorrectly
BWhether the model color is blue
CWhether the view cube is hidden
DWhether the file has a short name
Reveal Answer

A — Whether the profile crosses the centerline incorrectly

The strongest next step records the issue, identifies the likely cause, and turns the result into useful CAD evidence.
