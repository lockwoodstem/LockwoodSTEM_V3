Core Skill

What We Are Practicing

Key Idea 1

Mechanisms make motion useful and controlled.

Key Idea 2

Motion can be transferred, transformed, limited, or amplified.

Key Idea 3

A mechanism choice should match the function the system must perform.

Student Task

Classify Mechanisms by Motion

Analyze examples to determine their input motion, output motion, and mechanical purpose.

  1. Identify the moving components in each example.
  2. Classify input and output motion as rotary, linear, oscillating, or reciprocating.
  3. Describe how the mechanism changes or transfers motion.
  4. Select one mechanism type that may be useful later and explain why.

Quality check: Motion classifications describe what the parts actually do rather than only naming the device.
