IED Unit 1 • 12 Lessons

Engineering Documentation & Product Improvement

Learn the communication tools engineers use to understand an existing product, document how it works, and justify an evidence-based improvement.

Start Lesson 1.1Engineering Challenge HubBack to IED Hub
Unit Storyline

One connected documentation project

SketchRepresentMeasureInvestigateDocumentImprove

Each lesson adds evidence or documentation you can reuse in the final rocket improvement proposal.

How the Unit Fits Together

Four Phases

The lesson pages contain the core instruction, class flow, tasks, and resources for Unit 1.

Lessons 1.1–1.5

Communicate

Build technical sketching, multiview, line-convention, and dimensioning skills.

Lessons 1.6–1.8

Investigate

Reverse engineer the rocket, measure components, analyze fits, joints, and systems.

Lessons 1.9–1.11

Document

Create component records, an exploded view, BOM, and usable assembly instructions.

Lesson 1.12

Improve

Use the evidence collected throughout the unit to justify one engineering change.
