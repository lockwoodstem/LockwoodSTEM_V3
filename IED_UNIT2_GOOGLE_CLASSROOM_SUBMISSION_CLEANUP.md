# IED Unit 2 Google Classroom Submission Cleanup

Lessons 2.1–2.16 now use one combined **Assignment & Submission** section.

Each section is written so the content can be copied directly into a Google Classroom assignment and includes:
- exact work to complete;
- exact files/evidence to attach;
- standardized filenames;
- Fusion `.f3d` export directions where editable CAD files are required;
- Fusion `Save as Mesh → 3MF` directions where manufacturing files are required;
- Bambu Studio `.3mf` project-save directions where slicer files are required;
- exact screenshot/photo requirements;
- private-comment instructions for short written responses;
- clear no-file instructions for the existing 3D Printer Certification.

No other course units were intentionally modified.
