LockwoodSTEM - IED Unit 1 Lessons 1.1-1.4 Worksheet Update

This patch adds the finalized student worksheets to IED Lessons 1.1, 1.2, 1.3, and 1.4.

INSTALL
1. Open the active LockwoodSTEM_V3-main site folder.
2. Extract the contents of this ZIP directly into that folder.
3. Choose Replace files in the destination when prompted.
4. Upload/deploy the updated site as usual.
5. Hard-refresh the browser (Ctrl+F5) if an older lesson page remains cached.

WHAT CHANGED
- Lesson 1.1: Engineering Sketching & Line Conventions worksheet added.
- Lesson 1.2: Centerlines & Symmetry worksheet added.
- Lesson 1.3: 4-page portrait Isometric Sketching & Curved Features worksheet added.
- Lesson 1.4: 6-page Orthographic Projection & Multiview Sketching worksheet added.
- Each lesson has a Download Worksheet button near the top.
- Task and submission language now explicitly uses the worksheet.
- Resource Library entries were added/updated for all four worksheets.
- Both root and nested LockwoodSTEM_V3-main paths are included to match the site's duplicate-folder structure.
