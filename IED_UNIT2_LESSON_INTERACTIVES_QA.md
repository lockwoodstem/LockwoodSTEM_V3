# IED Unit 2 Lesson-Specific Interactives QA

## Scope

Added one lesson-specific interactive to each of the 18 IED Unit 2 lesson pages.

## Interactives added

1. **2.1 – CAD Modeling Plan:** Select the starting plane, base profile, and stable feature order from source documentation.
2. **2.2 – Fusion-Style Workspace Setup:** Locate the toolbar, browser, timeline, and view cube, then verify file naming and units.
3. **2.3 – Sketch Plane Selection:** Choose the plane that best captures the tolerance tester’s base profile.
4. **2.4 – Constraint Puzzle:** Apply the minimum geometric relationships needed to control a slot sketch without redundancy.
5. **2.5 – Dimension-Controlled Sketch:** Adjust overall width and hole location while viewing live geometry changes.
6. **2.6 – Extrusion Simulator:** Set extrusion distance, direction, and operation for the first solid body.
7. **2.7 – Cut and Hole Extents:** Match functional features to through-all or controlled-distance cuts.
8. **2.8 – Edge Treatment Decisions:** Choose fillet, chamfer, or no treatment based on safety, assembly, and inspection intent.
9. **2.9 – Revolve Builder:** Configure a closed half-profile, center axis, and full rotation for a rocket nose cone.
10. **2.10 – Rocket Fin Pattern:** Adjust fin count, calculate equal angular spacing, and choose the correct pattern axis.
11. **2.11 – Parametric Relationship Test:** Drive inner diameter from body diameter and wall thickness.
12. **2.12 – CAD Model Audit:** Identify organization, geometry, timeline, and requirement problems before export.
13. **2.13 – Mesh Export Check:** Select the correct body, format, units, and traceable file name.
14. **2.14 – Slicer Trade-Off Explorer:** Adjust layer height and infill while comparing estimated time and strength.
15. **2.15 – Printer Readiness Sequence:** Order the safe inspection, file verification, print-start, and first-layer workflow.
16. **2.16 – Tolerance Tester Builder:** Generate a labeled clearance series from start, step, and count values.
17. **2.17 – Post-Processing Inspection:** Choose cleanup actions that preserve the validity of the fit-test surfaces.
18. **2.18 – Clearance Recommendation:** Use simulated fit results to recommend a secure, removable rocket-assembly clearance.
