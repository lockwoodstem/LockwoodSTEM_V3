What You Are Learning

Learning Targets

  • Create a consistent record for significant rocket components.
  • Connect measurements, function, material, joining method, and interfaces in one documentation set.
  • Use sketches and labels to communicate geometry that text alone cannot explain.
  • Maintain traceability so parts can be identified later.

Class Flow

Work Through the Lesson

Day 1 — Component Records
  • Assign or confirm unique component names/item identifiers.
  • Document material, function, quantity, dimensions, and interfaces.
  • Create a sketch or useful photo reference for each significant component.
  • Record joining methods and orientation notes.
Day 2 — Documentation Quality Check
  • Complete missing measurements and component details.
  • Standardize names and item identifiers across the team.
  • Verify that every documented part can be matched to the physical component.
  • Peer-check another team member’s records for clarity and completeness.
Core Ideas

What to Pay Attention To

Traceability

A reader should be able to connect a written record to the exact physical part.

Consistency

Use the same names, item numbers, units, and terminology throughout the documentation package.

Reusability

Good documentation supports inspection, repair, reassembly, and future redesign—not just today’s assignment.

Engineering Check

Stop and verify before moving on

Pick up any documented part at random. Can you find its record quickly and identify its function, size, material, interfaces, and place in the assembly?

Your Task

Build the Rocket Component Documentation Set

Create a reliable component record for the significant parts in your team’s rocket. This becomes the source information for the next three lessons.

  1. Assign consistent part names and identifiers.
  2. Record quantity, material, function, and key dimensions.
  3. Add a sketch/photo reference and orientation notes.
  4. Document how the part connects to neighboring components.
  5. Review the full set for missing or conflicting information.

Use evidence: Keep sketches, measurements, observations, and revisions visible. Unit 1 is building one connected engineering documentation package.

What You Will Submit

Rocket Component Documentation Set

  • Organized records for all assigned significant components.
  • Measurements with units and consistent naming.
  • Sketch/photo evidence and interface notes.
  • Records complete enough to support the exploded view and BOM.

Before submitting: Check that your work is labeled, readable, complete, and consistent with the technical conventions used in this lesson.
