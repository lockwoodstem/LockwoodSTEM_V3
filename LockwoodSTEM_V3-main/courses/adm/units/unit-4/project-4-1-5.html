ADM Project 4.1.5

Aerospace Component Requirements Review

Define the mission need, interfaces, criteria, constraints, process route, material plan, and inspection strategy for the capstone component.

Back to Unit 4Student TaskWhat You Submit
Focus Question

How can a manufacturing team prove that an aerospace component concept is ready for detailed design?

Design. Verify. Manufacture. Inspect.

Learning targets

Today You Will Learn To

  • Translate a mission need into measurable component requirements.
  • Document interface, manufacturing, material, safety, and inspection constraints.
  • Defend a preliminary component concept during a requirements review.
Manufacturing context

Why This Matters

The capstone component is a lightweight UAV payload sensor mounting bracket or another teacher-approved non-flight-critical prototype. Teams must pass a requirements review before creating the final CAD model.

Educational prototype

Aerospace Application Boundary

This component is an educational manufacturing prototype. It is not approved for installation on a crewed aircraft, operational aircraft, or flight-critical system. Any real aerospace application would require additional engineering analysis, material certification, process control, inspection, documentation, and regulatory approval.

Project pathway

Milestones

01

Mission and interface definition

02

Requirements review and approval

Student task

Complete the Manufacturing Sequence

  1. 1
    Define the mission need and component function.
  2. 2
    Create a requirements table with measurable criteria and constraints.
  3. 3
    Develop an interface control sketch showing airframe, payload, fasteners, cable clearance, and datum references.
  4. 4
    Recommend stock material and a manufacturing process route.
  5. 5
    Complete preliminary calculations for stock use, mass target, and critical tolerance limits.
  6. 6
    Create at least two concepts and select one using evidence.
  7. 7
    Prepare and deliver a preliminary requirements review.
Safety and process control

Required Operating Habits

  • Use only teacher-approved files, tools, stock, speeds, feeds, and procedures.
  • Preserve the last verified working file or code version.
  • Stop immediately for unexpected motion, unusual sound, vibration, loose workholding, tool damage, or an unclear condition.
  • Do not operate the CNC mill without the required certification, permission, and supervision.
  • Record failed trials, defects, and interventions honestly.
Quality check

Before You Submit

  • Requirements are measurable and testable.
  • The selected concept fits the assigned interface and stock.
  • The team identifies unresolved risks rather than hiding them.
Student deliverables

What You Submit

  • Mission statement and requirements table
  • Interface control sketch
  • Concept sketches and selection matrix
  • Preliminary material and process plan
  • Manufacturing calculations
  • Requirements-review presentation
