ADM Project 4.1.5

Aerospace Component Requirements Review

Define the mission need, interfaces, criteria, constraints, process route, material plan, and inspection strategy for the capstone component.

Back to Unit 4Learning StepsStudent TaskWhat You Submit
Focus Question

How can a manufacturing team prove that an aerospace component concept is ready for detailed design?

Design. Verify. Manufacture. Inspect.

Learning targets

Today You Will Learn To

  • Translate a mission need into measurable component requirements.
  • Document interface, manufacturing, material, safety, and inspection constraints.
  • Defend a preliminary component concept during a requirements review.
Manufacturing context

Why This Matters

The capstone component is a lightweight UAV payload sensor mounting bracket or another teacher-approved non-flight-critical prototype. Teams must pass a requirements review before creating the final CAD model.

Educational prototype

Aerospace Application Boundary

This component is an educational manufacturing prototype. It is not approved for installation on a crewed aircraft, operational aircraft, or flight-critical system. Any real aerospace application would require additional engineering analysis, material certification, process control, inspection, documentation, and regulatory approval.

Learning sequence

Learn Before You Build

Complete these steps in order. Record the requested notes or evidence before moving to the graded activity.

15 min

1. Review the capstone mission

Read the Aerospace Component Mission Brief and highlight the mission need, required interfaces, measurable requirements, and educational-prototype limitation.

20 min

2. Convert needs into requirements

Follow the teacher model for writing measurable requirements using a value, unit, tolerance or limit, verification method, and source.

20 min

3. Plan the manufacturing route

Use the manufacturing process map and process-selection matrix to define the path from stock to inspected component.

20 min

4. Prepare for a formal review

Organize evidence so another manufacturing team can determine whether the concept is ready for detailed CAD development.

Detailed activity procedure

Complete the Aerospace Component Requirements Review

  1. 1
    Write the mission statement and component function in language that clearly identifies the need, user, system, and intended outcome.
  2. 2
    Create a requirements table. Each requirement must be measurable and include a verification method.
  3. 3
    Create the interface-control sketch showing all mounting patterns, payload or sensor location, cable path, fastener access, clearances, and datums.
  4. 4
    Document criteria, constraints, assumptions, and non-flight-critical application boundaries.
  5. 5
    Select the approved material or compare the teacher-provided material options using mass, machinability, cost, and availability.
  6. 6
    Define the starting stock dimensions and calculate preliminary utilization, mass, and tolerance limits.
  7. 7
    Develop at least two concepts and label how each concept satisfies the required interfaces.
  8. 8
    Use a weighted decision matrix to select the concept that will proceed to detailed design.
  9. 9
    Create the preliminary manufacturing route, tool list, workholding concept, inspection plan, and estimated operation order.
  10. 10
    Complete a preliminary risk table covering design, CAM, setup, machining, inspection, and schedule risks.
  11. 11
    Prepare a concise requirements-review presentation with the mission, interfaces, requirements, concept comparison, process plan, calculations, risks, and requested approval.
  12. 12
    Record reviewer feedback and classify every item as accepted, revised, deferred, or rejected with a reason.
  13. 13
    Submit the revised requirements package and obtain the design-gate approval before Activity 4.3.1.
Required checkpoints

Stop and Verify Before Moving On

Gate 1 — Requirements ready

Requirements are measurable and each includes a verification method.

Gate 2 — Concept selected

Interfaces, calculations, decision matrix, and manufacturing route support the selected concept.

Gate 3 — Review closed

Feedback is resolved and the concept is approved for CAD.

Safety and process control

Required Operating Habits

  • Use only teacher-approved files, tools, stock, speeds, feeds, and procedures.
  • Preserve the last verified working file or code version.
  • Stop immediately for unexpected motion, unusual sound, vibration, loose workholding, tool damage, or an unclear condition.
  • Do not operate the CNC mill without the required certification, permission, and supervision.
  • Record failed trials, defects, and interventions honestly.
Quality check

Before You Submit

  • Requirements are measurable and testable.
  • The selected concept fits the assigned interface and stock.
  • The team identifies unresolved risks rather than hiding them.
Student deliverables

What You Submit

  • Mission statement and requirements table
  • Interface control sketch
  • Concept sketches and selection matrix
  • Preliminary material and process plan
  • Manufacturing calculations
  • Requirements-review presentation
