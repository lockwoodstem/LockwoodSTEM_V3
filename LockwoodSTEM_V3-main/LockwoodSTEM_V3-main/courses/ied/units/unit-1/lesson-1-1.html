Engineering Sketching & Line Conventions

Focus question: How do engineers use sketches and standardized line types to communicate design ideas clearly?

Learning Targets

  • Explain why engineers sketch before CAD or fabrication.
  • Use light construction lines and darker final object lines.

  • Recognize center, dimension, and extension lines when they appear in technical drawings.

Class Flow

Work Through the Lesson

Day 1 — Sketching as Engineering Communication
  • Compare an engineering sketch with an artistic drawing and identify what makes the engineering sketch useful.
  • Practice straight-line quality, proportion, light construction lines, and darker final lines.
  • Learn the purpose and appearance of object, hidden, center, dimension, and extension lines.
  • Work through visible-versus-hidden examples as a class.
Day 2 — Object & Hidden Line Practice
  • Review how viewing direction changes which features can be seen.
  • Use the isometric reference in each problem to inspect the front, top, and right-side views.
  • Complete the Object & Hidden Line Practice Worksheet by adding only the missing lines.
  • Check line type, location, alignment, and neatness before submitting.
Core Ideas

What to Pay Attention To

Object lines

Thick, continuous lines show edges and boundaries that are directly visible in the selected view.

Hidden lines

Short, evenly spaced dashes show important edges that exist behind visible surfaces.

Construction lines

Very light lines help establish proportion and alignment before final linework is darkened.

Engineering Check

Stop and verify before moving on

Before you darken a line, ask: “Can I actually see this edge from this viewing direction?” If yes, use an object line. If the edge is blocked but still needs to be communicated, use a hidden line.

Your Task

Complete the Engineering Sketching & Line Conventions Worksheet

Use the isometric reference in each problem to complete the incomplete orthographic views. Add only the missing geometry, choosing object lines for visible edges and hidden lines for obscured edges.

  1. Begin with the Front view and identify features that face you directly.
  2. Move to the Top and Right views while keeping corresponding features aligned.
  3. Add missing visible edges with object lines.
  4. Add missing obscured edges with hidden lines using consistent dash spacing.
  5. Compare all three views to the isometric reference before submitting.

Use evidence: Keep sketches, measurements, observations, and revisions visible. Unit 1 is building one connected engineering documentation package.

What You Will Submit
