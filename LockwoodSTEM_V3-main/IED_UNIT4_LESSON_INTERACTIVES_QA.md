## Scope

1. **4.1 — Aerospace system chain:** input, process, output, and performance evidence.

10. **4.10 — Motor gear reduction:** calculate gear ratio, output speed, and torque tradeoff.
11. **4.11 — Weighted decision matrix:** calculate and select the highest-scoring concept.
12. **4.12 — System architecture:** connect sensor, controller, driver, motor, and mechanism.
13. **4.13 — CAD layout planning:** adjust clearance and axis alignment.
14. **4.14 — CAD motion and fit:** check component structure, pin clearance, and motion limits.
15. **4.15 — Structural build sequence:** order inspection, dry fitting, assembly, and verification.
16. **4.16 — Electrical fault diagnosis:** identify an open return path from voltage/current evidence.
17. **4.17 — Testing protocol:** select valid protocol steps and variables.
18. **4.18 — Data-quality audit:** identify missing units, uncontrolled variables, and insufficient trials.
19. **4.19 — Data analysis:** calculate a mean and select a supported conclusion.
20. **4.20 — Prototype iteration:** prioritize a function-blocking failure and justified revision.
21. **4.21 — Technical documentation audit:** verify mechanism, circuit, data, and revision evidence.
22. **4.22 — Demonstration planner:** sequence need, design, evidence, demonstration, and reflection.
