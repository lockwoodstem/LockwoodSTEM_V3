# ADM Unit 4 Aerospace CNC Website Update

## Full-site installation

Upload the contents of the updated `LockwoodSTEM_V3-main` folder to the GitHub repository that publishes LockwoodSTEM.org. Preserve the folder structure.

## Update-only installation

Copy the update-only package into the repository root and allow it to replace files with matching paths.

## Important deployment checks

1. Open `courses/adm/index.html` and confirm the Unit 4 card displays **Aerospace CNC Manufacturing**.
2. Open `courses/adm/units/unit-4.html` and test every lesson, challenge, interactive, and printable-resource link.
3. Confirm global search returns the new Unit 4 pages.
4. Confirm the Challenge Library displays the five new ADM Unit 4 challenges.
5. Verify the classroom CNC controller and post processor before using any G&M code on physical equipment.
6. Replace or revise the ADM syllabus and daily agenda separately when those documents are ready.

## Files intentionally replaced

The former cybersecurity, supply-chain, scheduling, packaging, and resilient-manufacturing Unit 4 student pages were removed from the active Unit 4 folder. The new lesson structure contains Activities 4.1.1–4.3.4, Projects 4.1.5 and 4.2.4, and Problem 4.3.5.
