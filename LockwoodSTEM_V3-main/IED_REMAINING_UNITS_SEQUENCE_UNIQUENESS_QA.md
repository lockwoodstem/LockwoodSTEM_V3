# IED Remaining Units Sequence and Uniqueness QA

## Scope

This revision covers all remaining IED lesson pages outside Unit 1:

- Unit 0: 12 lessons
- Unit 2: 18 lessons
- Unit 3: 17 lessons

- Unit 5: 18 lessons
- Total audited and updated: 87 lesson pages

Unit 1 was preserved exactly as provided in the latest sequence-simplified site package, including all 3D model sections.

## Curriculum revisions

- Removed the repeated **Engineering Workflow** section from every lesson in Units 2–5.
- Removed the repeated generic **Evidence Challenge** and **Scenario Response** template sections from Units 2–5.
- Replaced **Apply the Skill** with a lesson-specific Student Task title, activity description, four concrete steps, and a quality check.
- Rewrote the Interactive Check so it evaluates the evidence required for that specific lesson.
- Reduced every lesson to one or two required deliverables.
- Added one lesson-specific submission standard to every Unit 2–5 lesson.
- Simplified Unit 0 completion requirements to one or two primary deliverables while preserving its existing individualized activities.
- Replaced repeated helper copy with lesson-specific language so early lessons do not require later skills.

## Sequence audit

- Unit 2: sketch planes, constraints, extrusions, cuts, fillets/chamfers, revolves, patterns, parameters, slicing, certification, and post-processing
- Unit 3: joints, motion checks, drawing sheets, parts lists, and balloons
- Unit 4: statistics, mechanisms, friction, motion graphs, circuits, motors, decision matrices, system architecture, CAD, test protocols, and data analysis
- Unit 5: stakeholder research, the design brief, project management, concept selection, fabrication planning, testing, user feedback, life-cycle analysis, portfolio work, and presentation preparation
