- CAM: Autodesk Fusion Manufacture workspace
- Post: teacher-validated copy of Autodesk Mach3Mill
- NC file: `.tap`
- Controller: Mach3 configured for the DMC2 Mini
- Machine: DMC2 Mini CNC mill

## Safety note

The Autodesk generic Mach3Mill post is a baseline only. The teacher must validate the classroom copy against the DMC2 Mini Mach3 profile, units, axis directions, work offsets, spindle behavior, tool-change procedure, limits, and safe start/end behavior before student machining.
