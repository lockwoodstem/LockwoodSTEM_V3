POE UNIT 0 CUBESAT WEBSITE REBUILD

INSTALLATION
1. Open your active LockwoodSTEM_V3-main folder.
2. Extract the CONTENTS of this ZIP directly into that folder.
3. Choose Replace the files in the destination when prompted.

This patch includes both root-level and nested copies because the provided website archive contains a duplicated LockwoodSTEM_V3-main tree.
