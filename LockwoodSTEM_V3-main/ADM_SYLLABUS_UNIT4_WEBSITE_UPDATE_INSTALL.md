## After deployment

1. Wait for GitHub Pages to finish publishing.
2. Open the ADM course page.
3. Select **Open Syllabus (PDF)**.
4. Confirm page 2 lists **Unit 4 - Aerospace CNC Manufacturing**.
5. Use Ctrl+F5 if the browser still displays a cached copy.
