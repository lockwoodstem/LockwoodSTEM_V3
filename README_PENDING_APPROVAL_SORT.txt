LockwoodSTEM Teacher Dashboard - Pending Hands-On Approval Sort/Filter

Changes:
- Pending approvals default to sorting/grouping by certification type.
- Adds a certification filter for each equipment certification.
- Adds sort options: Certification Type, Student Name, and Class Period.
- Adds a visible pending-count indicator.
- Removes the previous 12-card display limit so all pending approvals can be reviewed.
- Approval behavior and backend data are unchanged.

Install:
Extract the contents directly into the active LockwoodSTEM_V3-main folder and replace existing files.
No Apps Script redeploy is required for this front-end-only change.
