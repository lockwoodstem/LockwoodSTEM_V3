# POE 1.4 Simulation Lesson Rebuild

Updated Lesson 1.4 to make the Gear Ratio & Gear Train Simulation the central learning experience.

## Updated / added files
- `courses/poe/units/unit-1/lesson-1-4.html` - rebuilt student lesson page
- `courses/poe/units/unit-1/interactive/gear-ratio-gear-train-lab.html` - embedded/full-screen simulation
- `downloads/worksheets/poe/unit-1/POE_1.4_Gear_Ratio_Gear_Train_Simulation_Worksheet.pdf` - student worksheet

## Lesson flow
1. Predict gear-pair behavior.
2. Use the simulation to investigate reduction, speed-up, and 1:1 gear pairs.
3. Build a simple gear train and investigate idler gears.
4. Use numerical evidence to choose a gear pair for the lunar sample-storage door mission.
5. Complete the exit check.
