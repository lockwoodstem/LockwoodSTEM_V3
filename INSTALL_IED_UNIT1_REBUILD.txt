INSTALLATION
1. Extract the contents of this ZIP directly inside your active LockwoodSTEM_V3-main folder.
2. Choose Replace files in the destination.
3. Double-click REMOVE_OLD_IED_UNIT1_PRESENTATIONS.bat if you also want the old PPTX files physically deleted from the site folder. (The website no longer links to them even if you skip this step.)
4. Hard refresh the website (Ctrl+F5).

NOTE
ZIP extraction can replace files but cannot delete existing files, so the small cleanup BAT is included to physically remove the legacy Unit 1 PPTX files.
