# Today's Lesson Integration

Extract this ZIP into the repository root and replace existing files.

Features:
- Homepage cards for IED, POE, and ADM using the published agenda sheets.
- Exact-day agenda row when available; otherwise the next scheduled lesson.
- Direct links to the matching lesson page, presentation, class link, and agenda.
- A contextual Today’s Lesson action bar on the Daily Agenda day view.
- Agenda deep links using `?course=IED&date=YYYY-MM-DD`.
- ADM falls back to its course/unit hub until individual ADM lesson pages are available.

No changes are made to CNAME.
