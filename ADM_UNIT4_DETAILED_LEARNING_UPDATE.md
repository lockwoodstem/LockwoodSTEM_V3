# ADM Unit 4 Detailed Learning Update

This repository rebuild adds a clearer student learning pathway to all 14 ADM Unit 4 activity, project, and problem pages.

Each page now includes:

- a four-part Learn Before You Build sequence;
- a detailed numbered activity procedure;
- required checkpoints or approval gates;
- official outside references and selected videos;
- stronger distinctions between the DMC2 Mini/Mach3 pathway and the FoxAlien model-specific pathway.

## Important FoxAlien note

The exact FoxAlien model is still required before publishing controller-specific homing, work-zero, spindle, post-processor, file-format, and program-execution instructions. The current pages direct students to the exact-model official manual and prohibit transferring Mach3 procedures to a FoxAlien unless verified by the teacher.

## External resources

External links use official NASA, Autodesk, MachSupport, FoxAlien, Haas, and NIST resources. Machine operation always follows the local classroom procedure and teacher approval.
