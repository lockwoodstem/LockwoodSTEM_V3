# Hidden Seating Display Page

A hidden, unlisted seating-display page was added at:

- `https://lockwoodstem.org/seating-display/`

The page embeds this Google Apps Script web app:

- `https://script.google.com/a/macros/lockwoodstem.org/s/AKfycby8tl7eyXTGURr02NBRNyHW0I8kfPyvdWAMUPUkfD3E3LQpWoir-ogI_d74zhgSzEVB/exec`

## Privacy and visibility

- The page is not linked from the site navigation or footer.
- The page is not included in the site search indexes.
- `noindex`, `nofollow`, `noarchive`, and `nosnippet` directives were added to the page.
- `/seating-display/` was added to `robots.txt`.
- The Google Apps Script deployment remains the actual access-control layer. A hidden URL by itself is not authentication.

## Included controls

- Refresh the embedded seating tool.
- Enter browser full-screen mode for classroom projection.
- Open the Google Apps Script tool in a separate tab if embedded Google sign-in is blocked.
