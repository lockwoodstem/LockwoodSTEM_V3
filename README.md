# LockwoodSTEM Website Repository

GitHub Pages repository for LockwoodSTEM.org.

## Publishing files

- `index.html` — main website homepage
- `courses.html` — course directory
- `agenda.html` — daily agenda
- `courses/ied/` — Introduction to Engineering Design
- `courses/poe/` — Principles of Engineering
- `courses/adm/` — Advanced Manufacturing
- `certifications/` — certification system and teacher tools
- `dashboard/` — student dashboard
- `resources/` and `downloads/` — resource library and downloadable files
- `assets/` — shared CSS, JavaScript, data, images, and models

## ADM Unit 4

Unit 4 is **Aerospace CNC Manufacturing: From Design Requirements to Machined Prototype**. The workflow uses Fusion for CAD/CAM, the DMC2 Mini with Mach3, and a model-specific pathway for the FoxAlien CNC.

## Deployment

Upload the contents of this folder to the root of the GitHub Pages publishing branch. Preserve `.nojekyll` and `CNAME`.

Maintenance reports from earlier update packages are archived under `maintenance/archive/` and are not part of the student navigation.
